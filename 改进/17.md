|---|---:|---:|

> enhancement-only 参数应被冻结或在 forward 中完全 bypass，不能影响输出。

# 4. Enhanced LQEA：保留原主干，只增加一层真正的跨层交互

# 4.1 当前 LQEA

当前输入：

```text
H3, H6, H9, H12
[B, 197, 768]
```

去掉 CLS：

```text
[B, 196, 768]
```

各层分别投影：

$$
P_l=W_l(\operatorname{LN}(H_l)),
\qquad
l\in\{3,6,9,12\}.
$$

得到：

```text
P3, P6, P9, P12
[B, 196, 256]
```

当前直接：

$$
P=\frac14(P_3+P_6+P_9+P_{12}).
$$

然后：

$$
w_i=\sigma(f_w(P_i)),
$$

$$
q_e=
\frac{\sum_i w_iP_i}
{\sum_iw_i+\epsilon},
$$

$$
\Delta v_q=f_q(q_e),
$$

最终：

$$
v_q=
v_0+\tanh(\gamma_q)\Delta v_q.
$$

---

# 4.2 当前 LQEA 最适合增强的位置

当前最大的问题不是 spatial weighting，而是：

> 四个视觉深度在进入 spatial weighting 前直接做等权平均，没有建模不同层级质量证据之间的关系。

因此本轮：

- 保留原来的 `patch_proj`
- 保留原来的 `patch_weight`
- 保留原来的 `quality_out`
- 保留原来的 outer quality gate

只替换中间这一段：

```text
Current:
P3/P6/P9/P12
    ↓
Average

Enhanced:
P3/P6/P9/P12
    ↓
Cross-Layer Interaction
    ↓
Adaptive Depth Aggregation
```

---

# 4.3 Enhanced LQEA 完整流程

```text
H3        H6        H9        H12
│         │         │          │
LN+Proj   LN+Proj   LN+Proj    LN+Proj
│         │         │          │
P3        P6        P9         P12
└─────────┴─────────┴──────────┘
                    │
          stack layer dimension
                    │
          [B,196,4,256]
                    │
          Cross-Layer Interaction
                    │
          Adaptive Depth Fusion
                    │
              [B,196,256]
                    │
        Quality-aware Patch Weighting
                    │
            Weighted Pooling
                    │
           Quality Projection
                    │
             Gated Injection
```

---

# 4.4 Step A：构造同位置跨层序列

对于第 $i$ 个空间 patch：

$$
Z_i=
[P_{3,i},P_{6,i},P_{9,i},P_{12,i}]
\in\mathbb{R}^{4\times D}.
$$

实现：

```python
Z = torch.stack([P3, P6, P9, P12], dim=2)
# [B, 196, 4, 256]
```

用于 attention 时 reshape：

```python
Z_attn = Z.reshape(B * 196, 4, 256)
```

注意：

> attention sequence length 只有 4，不是在 196 个 image patches 上重新做大型 Transformer。

所以计算量很小。

---

# 4.5 Step B：Layer Embedding

增加：

```python
self.layer_embed = nn.Parameter(torch.zeros(1, 1, 4, dim))
```

但不要直接把 layer embedding 加进最终 residual 主路径。

建议：

```python
Z_ctx = Z + self.layer_embed
```

仅作为 cross-layer interaction 的输入。

这样可以表达：

```text
token 1 → layer 3
token 2 → layer 6
token 3 → layer 9
token 4 → layer 12
```

初始化为 0。

---

# 4.6 Step C：单层 Cross-Layer Interaction Block

不要堆多个 Transformer Block。

只用：

```text
PreNorm
→ Multi-Head Self-Attention
→ residual
→ PreNorm
→ small FFN
```

建议：

```text
dim       = 256
num_heads = 4
ffn_dim   = 512
dropout   = 0.0
num_block = 1
```

伪代码：

```python
class CrossLayerBlock(nn.Module):
    def __init__(self, dim=256, num_heads=4):
        self.norm1 = nn.LayerNorm(dim)
        self.attn = nn.MultiheadAttention(
            embed_dim=dim,
            num_heads=num_heads,
            dropout=0.0,
            batch_first=True,
        )

        self.norm2 = nn.LayerNorm(dim)
        self.ffn = nn.Sequential(
            nn.Linear(dim, dim * 2),
            nn.GELU(),
            nn.Linear(dim * 2, dim),
        )

    def forward(self, z):
        a, _ = self.attn(
            self.norm1(z),
            self.norm1(z),
            self.norm1(z),
            need_weights=False,
        )
        z1 = z + a
        z2 = z1 + self.ffn(self.norm2(z1))
        return z2
```

但是为了保持 V26 initial forward 完全一致：

> 不要直接用 `z2` 替换 `Z`。

应该定义 enhancement residual：

```python
delta_z = cross_layer_block(Z_ctx) - Z_ctx
```

再：

```python
Z_inter = Z + torch.tanh(self.cross_layer_gate) * delta_z
```

其中：

```python
self.cross_layer_gate = nn.Parameter(torch.tensor(0.0))
```

因此初始：

$$
\tanh(0)=0,
$$

得到：

$$
Z_{\text{inter}}=Z.
$$

也就是说：

> Enhanced LQEA 在训练开始前与 Current LQEA 完全 function-equivalent。

---

# 4.7 Step D：Adaptive Depth Aggregation

当前固定：

$$
\frac14(P_3+P_6+P_9+P_{12})
$$

改为 patch-wise depth weighting。

增加一个共享 depth scorer：

```python
self.depth_score = nn.Sequential(
    nn.Linear(dim, 64),
    nn.GELU(),
    nn.Linear(64, 1),
)
```

得到：

```python
depth_logits = self.depth_score(Z_inter)
# [B,196,4,1]
```

然后：

```python
alpha = softmax(depth_logits, dim=2)
```

即：

$$
\alpha_{i,l}
=
\operatorname{Softmax}_{l}
\left(
f_d(Z_{i,l}^{\text{inter}})
\right).
$$

最后：

$$
P_i=
\sum_l
\alpha_{i,l}Z_{i,l}^{\text{inter}}.
$$

实现：

```python
P = (alpha * Z_inter).sum(dim=2)
# [B,196,256]
```

---

# 4.8 Depth scorer 必须做 neutral initialization

为了让 V27 初始结果与 V26 完全一致：

最后一个：

```python
nn.Linear(64, 1)
```

初始化：

```python
weight = 0
bias   = 0
```

于是初始：

```text
depth_logits = [0,0,0,0]
```

所以：

$$
\alpha_{i,l}=\frac14.
$$

同时 cross-layer gate 初始为 0。

因此：

$$
P_i^{V27-init}
=
\frac14
(P_{3,i}+P_{6,i}+P_{9,i}+P_{12,i})
=
P_i^{V26}.
$$

这个性质必须保留。

---

# 4.9 后续 spatial quality pathway 完全不改

仍然：

$$

$$

$$

$$

# 4.10 Enhanced LQEA 的最终解释

Enhanced LQEA 形成两个连续的信息选择层次：

```text
Level 1: Hierarchical Selection
同一个空间位置，更应依赖浅层、中层还是深层视觉证据？

Level 2: Spatial Selection
所有图像区域中，哪些 patch 对主观质量更重要？
```

即：

```text
Cross-Layer Interaction
        ↓
Adaptive Depth Selection
        ↓
Spatial Quality Selection
```

这是本轮 LQEA 唯一增强方向。

# 5. Enhanced CSAE：保留原 scalar correspondence，增加 region-relation residual refinement

# 5.1 当前 CSAE

当前 global：

$$
s_g=\cos(v_g,t_g).
$$

regional：

1. prompt 有效 token 分成 $K=4$ 个连续 token groups；
2. group mean 得到 $t_k$；
3. $t_k$ 与 196 个 visual patches 算 cosine；
4. 取 Top-3；
5. Top-3 similarity 求平均得到 $r_k$；
6. fragment relevance 由 $\cos(t_k,t_g)$ 得到；
7. softmax 后对 $r_k$ 聚合得到 $s_r$。

最终：

$$
e_{\text{base}}
=
f_{\text{corr}}([s_g,s_r]).
$$

当前路径本身继续保留。

---

# 5.2 当前 CSAE 最适合增强的位置

当前 CSAE 已经能够：

> 找到与 prompt fragment 最对应的 image regions。

但在找到 Top-K 区域以后，只保留：

```text
Top-K similarity mean
→ 一个 scalar
```

大量视觉区域表示被丢掉。

所以本轮不改变：

```text
Token Grouping
Fragment-Patch Matching
Top-K Region Mining
Fragment Relevance
```

只增加：

```text
Top-K visual feature aggregation
        ↓
Text-Region Relation Encoding
        ↓
Regional relation embedding
```

同时给 global scope 增加对应的 global relation embedding。

---

# 5.3 Enhanced CSAE 总体结构

```text
                      CSAE
                        │
            ┌───────────┴───────────┐
            │                       │
      Existing Scalar Path     Relation Enhancement
            │                       │
       s_g + s_r              ┌─────┴─────┐
            │                 │           │
correspondence_proj     Global Relation  Regional Relation
            │                 │           │
         e_base               e_g         e_r
            │                 └─────┬─────┘
            │                  Cross-Scope
            │                   Refinement
            │                       │
            │                    delta_e
            │                       │
            └──────────────┬────────┘
                           │
          e_a = e_base + gate * delta_e
```

这样既：

- 保留当前已经验证有效的 CSAE；
- 又增加更丰富的区域关系建模；
- 并且可以 neutral-init，初始完全等价于 V26。

---

# 5.4 Step A：继续计算原本的 scalar evidence

完全复用原 CSAE 逻辑：

$$
s_g=\cos(v_g,t_g).
$$

fragment：

$$
t_k=
\operatorname{Norm}
\left(
\frac{1}{|F_k|}
\sum_{j\in F_k}T_j
\right).
$$

patch similarity：

$$
S_{k,i}=\cos(t_k,V_i).
$$

Top-R：

$$
\mathcal R_k
=
\operatorname{TopR}(S_{k,:}).
$$

原有 scalar：

$$
r_k=
\frac1R
\sum_{i\in \mathcal R_k}S_{k,i}.
$$

fragment relevance：

$$
a_k=\cos(t_k,t_g),
$$

$$
\alpha_k=\operatorname{Softmax}(a_k).
$$

regional scalar：

$$
s_r=
\sum_k\alpha_kr_k.
$$

base correspondence embedding：

$$
e_{\text{base}}
=
f_{\text{corr}}([s_g,s_r]).
$$

这部分必须和当前 `MGSCRefined` function-equivalent。

---

# 5.5 Step B：Top-K Region Feature Aggregation

原来 Top-K 之后只保留 similarity。

现在同时 gather 对应 visual patch：

```python
top_values, top_indices = torch.topk(sims, k=topk, dim=-1)
```

得到：

```text
top_values  [B,R]
top_indices [B,R]
```

根据 indices gather：

```text
V_top [B,R,512]
```

在 Top-R 内部做 soft weighting：

```python
beta = softmax(top_values, dim=-1)
```

不新增 temperature 超参数。

即：

$$
\beta_{k,i}
=
\operatorname{Softmax}_{i\in\mathcal R_k}
(S_{k,i}).
$$

聚合：

$$
v_k
=
\sum_{i\in\mathcal R_k}
\beta_{k,i}V_i.
$$

得到：

```text
v_k [B,512]
```

含义：

> 与第 $k$ 个 prompt fragment 最相关的视觉区域表征。

---

# 5.6 Step C：Text-Region Relation Encoding

对于：

```text
t_k : fragment representation [B,512]
v_k : selected region representation [B,512]
```

构造关系特征：

$$
R_k=
[
t_k,\;
v_k,\;
t_k\odot v_k,\;
|t_k-v_k|
].
$$

维度：

```text
[B, 2048]
```

四部分含义：

```text
t_k              fragment semantic evidence
v_k              matched visual region
t_k ⊙ v_k        element-wise consistency
|t_k - v_k|      element-wise discrepancy
```

增加共享 Relation Encoder：

```python
self.relation_encoder = nn.Sequential(
    nn.Linear(512 * 4, dim),
    nn.GELU(),
    nn.LayerNorm(dim),
    nn.Linear(dim, dim),
    nn.GELU(),
    nn.LayerNorm(dim),
)
```

得到：

$$
c_k=f_r(R_k)\in\mathbb R^D.
$$

不要给每个 fragment 单独一个 encoder。

四个 fragments 共用同一个：

```text
relation_encoder
```

以控制参数量。

---

# 5.7 Step D：Fragment Relation Aggregation

继续使用原来的：

$$
\alpha_k
=
\operatorname{Softmax}(\cos(t_k,t_g)).
$$

但原来聚合 scalar：

$$
s_r=\sum_k\alpha_kr_k.
$$

新增 relation embedding：

$$
e_r=
\sum_k\alpha_kc_k.
$$

因此：

```text
s_r → 保留，用于 current CSAE base path
e_r → 新增，用于 relation enhancement path
```

---

# 5.8 Step E：Global Relation Encoding

当前 global scope 只有：

$$
s_g=\cos(v_g,t_g).
$$

保留 $s_g$。

同时构造：

$$
R_g=
[
v_g,\;
t_g,\;
v_g\odot t_g,\;
|v_g-t_g|
].
$$

使用和 regional **同一个**：

```python
relation_encoder
```

得到：

$$
e_g=f_r(R_g)\in\mathbb R^D.
$$

共享 encoder 的好处：

> global relation 和 regional relation 被映射到统一的 correspondence relation space。

---

# 5.9 Step F：Cross-Scope Relation Refinement

输入：

$$
[
e_g,\;
e_r,\;
e_g\odot e_r
].
$$

不要继续增加更多 handcrafted terms。

增加：

```python
self.scope_refine = nn.Sequential(
    nn.Linear(dim * 3, dim),
    nn.GELU(),
    nn.LayerNorm(dim),
)
```

得到：

$$
\Delta e_a
=
f_s
([
e_g,e_r,e_g\odot e_r
]).
$$

# 5.10 Step G：Residual relation gate

最终不要直接：

```text
e_a = delta_e
```

而是：

$$
e_a
=
e_{\text{base}}
+
\tanh(\gamma_a)\Delta e_a.
$$

其中：

```python
self.relation_gate = nn.Parameter(torch.tensor(0.0))
```

所以初始化：

$$
e_a=e_{\text{base}}.
$$

因此：

# 19. 预先固定的决策标准

为了避免跑完以后“看数字再改标准”，提前固定。

---

## Case A：E1 明确提升

如果：

$$
\Delta MainScore_{E1}\ge +0.002
$$

且：

```text
ΔSRCC >= -0.001
```

则：

> Enhanced LQEA 通过。

如果：

```text
ΔMainScore >= +0.003
```

则认为提升比较清楚。

---

## Case B：E2 明确提升

同理：

$$
\Delta MainScore_{E2}\ge +0.002
$$

且：

```text
ΔSRCC >= -0.001
```

则：

> Enhanced CSAE 通过。

---

## Case C：E3 最好

如果：

```text
E1 > REF
E2 > REF
E3 > E1
E3 > E2
```

则是最理想情况：

```text
Current Full
   ↓
Enhanced LQEA 有独立贡献
Enhanced CSAE 有独立贡献
   ↓
Enhanced Full 最优
```

此时 E3 才有资格成为新的候选最终模型。

---

## Case D：只有一个 enhancement 有效

例如：

```text
E1 > REF
E2 ≈ REF / < REF
E3 ≈ E1
```

则：

> 只保留 Enhanced LQEA。

反过来同理。

不要为了结构复杂强行采用失败模块。

---

## Case E：E1/E2 都有效，但 E3 不比单模块好

例如：

```text
E1 = 0.890
E2 = 0.891
E3 = 0.890
```

则：

> 不采用 E3。

优先选择最简单且性能最高的单 enhancement。

原因：

> 两个独立有效不代表联合后仍有互补。

---

## Case F：三个都没有明显提升

如果：

```text
|ΔMainScore| < 0.001~0.002
```

则：

> V27 enhancement 试验失败。

直接保留当前 V26。

禁止继续：

```text

改 FFN ratio
改 TopK
加第二层 attention
换 cross-attention
继续堆模块
```

这次探索到此为止。
