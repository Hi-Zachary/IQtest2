# Frozen CLIP + DG-MPQ + CADR：去 LoRA 双模块最终验证方案

> 目标：验证一个新的核心假设：
>
> **当前 Visual LoRA 可能已经在 CLIP backbone 内部承担了较多 IQA task adaptation，从而压缩了后续模块的边际收益。**
>
> 因此尝试完全冻结 CLIP vision encoder，不使用 LoRA，让：
>
> - **DG-MPQ** 负责 feature-side / representation-side quality adaptation；
> - **CADR** 负责 predictor-side / mapping-side quality adaptation。
>
> 最终候选：
>
> ```text
> Frozen CLIP
>     +
> DG-MPQ
>     +
> CADR
> ```
>
> 这次不再设计新模块，也不扩 DG-MPQ / CADR，只验证“去掉 LoRA 后，两个已知最合理模块是否能承担原本 backbone adaptation 的作用”。

---

# 1. 为什么值得验证“去掉 LoRA”

当前 backbone 中 Visual LoRA：

```text
CLIP ViT-B/16
Visual encoder only
target modules: q_proj / k_proj
rank r = 4
alpha = 8
```

LoRA 会直接改变 Transformer 内部：

$$
Q=(W_Q+\Delta W_Q)X,
$$

$$
K=(W_K+\Delta W_K)X.
$$

因此它不是一个简单的最后层 adapter，而是会逐层影响 self-attention，并继续影响：

```text
H3
H6
H9
H12
global_v
```

也就是说，目前 DG-MPQ 接收到的并不是完全 frozen CLIP features，而是：

> **已经被 IQA supervision 适配过的 visual hidden states。**

这可能解释此前的现象：

```text
LoRA
  ↓
task-adapted CLIP features
  ↓
DG-MPQ
  ↓
已经较强
  ↓
再加 QARD / DAPS / CADR / DCAR / HMQE / DCGA
  ↓
边际信息大量重叠
  ↓
几乎不涨
```

因此存在一个值得检验的假设：

> 去掉 LoRA 后，后续显式质量建模模块可能获得更大的功能空间。

---

# 2. 为什么两个模块选择 DG-MPQ + CADR

不是随便选两个。

这是目前所有已尝试模块中，在机制和实验上最合理的一对。

---

## 2.1 Module 1：DG-MPQ

**DG-MPQ — Deviation-Guided Multi-Level Patch Quality Modeling**

它负责：

> **Feature-side Quality Adaptation**

即把 Frozen CLIP 的通用视觉特征转换为更适合 IQA 的 degradation-aware representation。

核心：

```text
H3 / H6 / H9 / H12
    ↓
layer-wise projection
    ↓
multi-level patch representation
    ↓
local-global semantic deviation
    ↓
deviation-conditioned patch importance
    ↓
weighted aggregation
    ↓
quality residual
```

数学上：

$$
P=
\frac{
P_3+P_6+P_9+P_{12}
}{4},
$$

$$
d_i=
1-\cos(P_i,g),
$$

$$
w_i=
\sigma(f_w([P_i,d_i])),
$$

$$
q_{local}
=
\frac{
\sum_iw_iP_i
}{
\sum_iw_i+\epsilon
},
$$

$$
\Delta v_q=f_{out}(q_{local}).
$$

然后：

$$
v_q
=
v_0+
\tanh(\lambda_q)\Delta v_q.
$$

DG-MPQ 是目前唯一在多个实验中表现出稳定正增益的结构，因此必须保留。

---

## 2.2 Module 2：CADR

**CADR — Content-Adaptive Dynamic Regressor**

它负责：

> **Predictor-side Quality Adaptation**

即不改变视觉特征，而是让不同图像使用不同的 quality mapping。

当前 static predictor：

$$
q_{base}=w_0^Th_q+b_0.
$$

CADR 使用 global semantic content：

$$
c=f_c(global_v),
$$

由 HyperNet 生成：

$$
[\Delta w(x),\Delta b(x)]
=
H(c).
$$

动态 correction：

$$
\Delta q=
\frac{
\Delta w(x)^T LN(h_q)
}{
\sqrt D
}
+\Delta b(x).
$$

最终：

$$
q=q_{base}+\Delta q.
$$

因此两个模块职责非常清楚：

```text
DG-MPQ：
“怎样得到 quality-aware representation？”

CADR：
“怎样针对当前图像调整 representation → MOS 的映射？”
```

---

# 3. 为什么不选其他模块

## QARD

功能：

```text
query → patch retrieval / attention
```

与 DG-MPQ 都在重新选择局部视觉信息。

且 AIGIQA-20K 已验证：

```text
≈ 0 gain
```

不选。

---

## DAPS

同样属于：

```text
patch importance / patch scoring
```

与 DG-MPQ 功能高度重复。

不选。

---

## HMQE

本质仍然在：

```text
multi-level visual representation
```

上扩展 DG-MPQ。

V20 已经证明其机制激活但无新增性能。

不选。

---

## DCGA

本质是 DG-MPQ aggregation 的复杂化：

```text
hierarchical deviation
+
dispersion
```

V20 同样无收益。

不选。

---

## DCAR

比 CADR 更复杂，但 V19：

```text
没有超过 V18 CADR。
```

说明给 dynamic predictor 加 degradation profile 并未带来额外价值。

因此使用更简单、已有弱正增益的 CADR。

---

## PTLC / MSRC / MSCM / HCMI / TCAP

主要属于：

```text
cross-modal fine-grained interaction
alignment relation
patch-text relation
```

此前均未取得稳定收益。

不选。

---

# 5. 最关键的研究问题

这次不是问：

> Frozen CLIP 一定比 LoRA 好吗？

而是回答三个问题。

---

## Q1：没有 LoRA 后，DG-MPQ 的相对贡献是否变大？

定义：

```text
Frozen baseline:
F0

Frozen + DG-MPQ:
F1
```

看：

$$
\Delta_{DG}^{Frozen}
=
F1-F0.
$$

再和现有 LoRA 条件下：

$$
\Delta_{DG}^{LoRA}
=
L1-L0
$$

比较。

如果：

$$
\Delta_{DG}^{Frozen}
>
\Delta_{DG}^{LoRA},
$$

说明：

> LoRA 与 DG-MPQ 确实存在一定 feature adaptation 功能重叠。

---

## Q2：没有 LoRA 后，CADR 的相对贡献是否变大？

定义：

```text
Frozen + DG-MPQ:
F1

Frozen + DG-MPQ + CADR:
F2
```

看：

$$
\Delta_{CADR}^{Frozen}
=
F2-F1.
$$

目前 LoRA 条件下 CADR：

```text
VAL:
约 +0.0014

TEST:
约 +0.0023
```

如果 Frozen 条件变成：

```text
+0.003
+0.004
甚至更高
```

则说明：

> 在 backbone 不做 task adaptation 时，prediction-side adaptive mapping 的价值更明显。

---

## Q3：Frozen 双模块最终绝对性能能否追平 LoRA 模型？

这是最终最重要的问题。

比较：

$$
F2
$$

和：

$$
L1=
\text{LoRA + DG-MPQ}.
$$

如果：

```text
F2 >= L1
```

甚至略高，则推荐正式去掉 LoRA。

如果：

```text
F2 明显低于 L1
```

则不能为了结构漂亮牺牲性能。

# 8. 初始化原则

去掉 LoRA 后，不可能与当前 LoRA 模型做完全相同 function init。

因此新的 Frozen 实验需要一个新的 matched-init：

```text
frozen_seed42.pth
```

流程：

1. 加载原始 CLIP ViT-B/16；
2. 不创建 LoRA；
3. freeze vision encoder；
4. 初始化所有 quality branch / DG-MPQ / CADR 参数；
5. 保存完整 state dict；
6. F0/F1/F2 全部从这一 state dict `strict=True` 加载。

这样：

```text
F0 / F1 / F2
```

内部仍然是公平 matched-init。

---

# 9. CADR 的初始化

继续沿用 V18 的设计：

HyperNet 最后一层：

```python
nn.init.zeros_(self.hyper[-1].weight)
nn.init.zeros_(self.hyper[-1].bias)
```

因此初始化时：

$$
\Delta w=0,
$$

$$
\Delta b=0,
$$

所以：

$$
q=q_{base}.
$$

即：

```text
F2 初始 function == F1
```

这是非常重要的 controlled comparison。

方法故事：

### Contribution 1：DG-MPQ

> 在冻结的通用 VLM 表征之上，通过多层局部特征与局部-全局语义偏差显式构造 degradation-aware visual quality representation。

例如：

# DCA-IQA
Degradation-aware Content-Adaptive IQA

内部：

### DG-MPQ
Deviation-Guided Multi-Level Patch Quality Modeling

### CADR
Content-Adaptive Dynamic Regression

整个逻辑：

```text
Frozen General-Purpose VLM
        ↓
Explicit Degradation Modeling
        ↓
Content-Adaptive Quality Mapping
        ↓
MOS
```

# 29. 面试/论文解释

可以这样说：

> 我们最初使用 LoRA 对 CLIP 视觉编码器进行参数高效适配，但进一步实验发现，backbone adaptation 与显式的质量建模模块可能存在功能重叠。因此我们进一步探索完全冻结 CLIP，让任务相关学习集中在提出的两个轻量模块中。

> 第一个 DG-MPQ 从冻结 CLIP 的多层视觉特征中显式建模局部生成退化，通过局部和全局语义偏差引导质量证据聚合；第二个 CADR 则根据图像内容动态调整最终的质量映射规则，分别承担 representation-side 和 prediction-side adaptation。

前提：

> 只有实验真的支持 Frozen 双模块时才这样写。

# 30. 最终停止规则

这次是一个明确的 hypothesis test，不是新一轮无限搜索。

跑完：

```text
F0
F1
F2
```

后：

### 如果 F2 追平 LoRA，并且 F2-F1 明显

采用：

```text
Frozen + DG-MPQ + CADR
```

### 如果 F2 明显追不上 LoRA

回到：

```text
LoRA + DG-MPQ
```

### 如果 CADR Frozen 后仍只有 <+0.001

彻底放弃 CADR。

### 无论结果怎样

> 不再设计新的“替代 LoRA 模块”。

这组实验的意义，就是最终回答：

> **显式质量建模模块能不能替代 backbone-level LoRA adaptation？**
