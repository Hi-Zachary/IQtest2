# V19 最终推荐方案：DG-MPQ+ + DCAR

> 当前可靠基线：`1f4b5564861b4ae9a7d7a79fdbfc1c841a92106e`
>
> 目标：不把已经稳定有效的 DG-MPQ 生硬拆成两个“凑数模块”，而是对 DG-MPQ 做一次低风险扩展，并把它产生的多层退化信息显式传给第二个预测模块。

## 1. 当前结论

AIGIQA-20K 当前结果：

```text
VAL MainScore
R0            0.8773
B1 DG-MPQ     0.8832
Full + CADR   0.8846

TEST MainScore
R0            0.8854
B1 DG-MPQ     0.8891

```

因此：

```text
DG-MPQ:
VAL  +0.0059

CADR on top of DG-MPQ:
VAL  +0.0014
TEST +0.0023
```

DG-MPQ 已经是可靠核心；CADR 有弱正增益，但目前单独作为第二贡献略显单薄。

V19 推荐做成：

```text
Module 1: DG-MPQ+
    multi-level degradation perception
    + deviation-aware scale fusion
                ↓
      multi-level degradation profile
                ↓
Module 2: DCAR
    degradation-conditioned adaptive regression
```

两个模块分别回答：

```text
DG-MPQ+:
“哪里、在哪个特征层次上出现了质量异常？”

DCAR:
“在当前内容和退化模式下，这些质量证据应该怎样映射成主观分数？”
```

## 2. 为什么不直接把 DG-MPQ 一刀切成两个模块

当前 DG-MPQ 已包含：

1. H3/H6/H9/H12 多层 patch 投影；
2. local-global semantic deviation；
3. deviation-guided patch weighting；
4. weighted aggregation；
5. quality residual generation。

如果简单把 1+2 叫模块 A、3+4+5 叫模块 B，虽然形式上是两个模块，但很容易被质疑为“把一个连续模块拆成两个名字”。

所以不建议这么做。

更合理的是：

- DG-MPQ 仍然是完整的 degradation representation module；
- 只扩展它最明显的弱点：当前四层永远等权平均；
- 同时把 DG-MPQ 内部已经计算出来、但原本没有显式利用的多层退化信息交给第二模块；
- 第二模块继续基于 HyperIQA 的成熟思想做 sample-specific dynamic prediction。

这样第二模块不是挂件，但也不会破坏 DG-MPQ 当前已经验证好的主干。

---

## 3. DG-MPQ 的来源

当前 `dg_mpq.py` 本身已经记录：

```text
TeMu-IQA inspired multi-level patch representation
+
旧 DMSQR 的 local-global semantic deviation
+
针对 AIGC-IQA 重新设计的 deviation-guided aggregation
```

TeMu-IQA（CVPRW 2025）本身也不是只有一个创新，它包括：

- multi-level VLM features；
- TPS：Text-Guided Patch Scoring；
- LDG：Local Distortion Guidance。

论文：
https://openaccess.thecvf.com/content/CVPR2025W/NTIRE/html/Park_Text-Guided_Patch_Scoring_and_Local_Distortion_Guidance_for_Image_Quality_CVPRW_2025_paper.html

当前 DG-MPQ 真正借到的主要是“multi-level CLIP features”这一成熟思路；`1-cos(local, global)` 以及后续权重聚合是当前工程逐步演化出来的任务适配。

HyperIQA（CVPR 2020）的核心则是：

```text
content understanding
→ hypernetwork
→ sample-specific target predictor parameters
→ quality prediction
```

论文：
https://openaccess.thecvf.com/content_CVPR_2020/html/Su_Blindly_Assess_Image_Quality_in_the_Wild_Guided_by_a_CVPR_2020_paper.html

V19 的第二模块保留这一“动态生成预测规则”的成熟核心，但 conditioner 不再只有 global content，而加入 DG-MPQ 输出的显式 degradation profile。

# Module 1：DG-MPQ+

## 4. 保留当前有效主体

当前四层：

$$
P_3,\ P_6,\ P_9,\ P_{12}
$$

分别经过独立投影。

当前实现直接：

$$
P = \frac{P_3+P_6+P_9+P_{12}}{4}.
$$

后续：

$$
d_i = 1-\cos(P_i,g),
$$

$$
w_i = \sigma(\operatorname{MLP}([P_i,d_i])),
$$

$$
q_{local}
=
\frac{\sum_iw_iP_i}{\sum_iw_i+\epsilon},
$$

$$
\Delta q=f_{out}(q_{local}).
$$

这一后半段全部保留。

---

## 5. 唯一结构扩展：DASF

加入：

**DASF — Deviation-Aware Scale Fusion**

目的不是引入复杂 attention，而是解决：

> 为什么 H3/H6/H9/H12 对所有图片都必须固定各占 25%？

对于每层先计算：

$$
d_{l,i}=1-\cos(P_{l,i},g).
$$

再计算三个层级统计：

$$
\mu_l=Mean(d_l),
$$

$$
\sigma_l=Std(d_l),
$$

$$
\tau_l=Mean(Top10\%(d_l)).
$$

形成：

$$
s_l=[\mu_l,\sigma_l,\tau_l].
$$

共享小 MLP：

$$
a_l=f_s(s_l),
$$

然后：

$$
\alpha_l =
\frac{e^{a_l}}{\sum_ke^{a_k}}.
$$

最后：

$$
P=\sum_l\alpha_lP_l.
$$

### 必须 zero-init

`scale_score` 最后一层全部初始化为 0。

所以训练开始：

$$
\alpha_3=\alpha_6=\alpha_9=\alpha_{12}=1/4.
$$

也就是说 V19 的初始 DG-MPQ+ 与当前 DG-MPQ 完全一致，然后再由数据决定是否需要改变不同层的重要性。

这是一个低风险扩展。

---

## 6. 给第二模块输出 Multi-Level Degradation Profile

这里才是“从 DG-MPQ 拆一点给第二模块”的核心，但不是删除 DG-MPQ 原功能。

对于每一层额外计算 degradation prototype：

$$
r_l=
\frac{
\sum_i d_{l,i}P_{l,i}
}{
\sum_i d_{l,i}+\epsilon
}.
$$

得到：

```text
r3
r6
r9
r12
```

每个都是 `[B,256]`。

它们描述：

> 在不同 CLIP feature depth 下，哪些局部特征最偏离全局语义。

同时输出：

```text
stats = [
  mean/std/top10% of d3,
  mean/std/top10% of d6,
  mean/std/top10% of d9,
  mean/std/top10% of d12
]

scale_weight = [α3, α6, α9, α12]
```

因此 DG-MPQ+ forward 推荐：

```python
delta_q, deg_profile = self.dg_mpq(
    h3, h6, h9, h12
)

deg_profile = {
    "prototype": prototypes,    # [B,4,256]
    "stats": stats,             # [B,4,3]
    "scale_weight": alpha,      # [B,4]
}
```

DG-MPQ 本身仍输出原来的 `delta_q`，所以它依然是一个完整模块。

# Module 2：DCAR

## 7. DCAR 的定位

名称：

**DCAR — Degradation-Conditioned Adaptive Regressor**

V18 CADR：

```text
global_v
→ HyperNet
→ Δw, Δb
→ dynamic correction
```

问题是：

> controller 知道图像是什么内容，但不知道 DG-MPQ 到底发现了什么退化。

而 V18 的实验恰好表现为：

```text
CADR-only ≈ R0
DG-MPQ + CADR = 小幅正增益
```

这提示最合理的下一步不是“把 HyperNet 加深”，而是：

> 给 dynamic predictor 真正的 degradation condition。

---

## 8. Degradation Profile Encoder

输入四个：

```text
r3/r6/r9/r12
```

使用共享 projector：

```python
prototype_proj = nn.Sequential(
    nn.LayerNorm(256),
    nn.Linear(256, 32),
    nn.GELU(),
)
```

四层得到：

```text
4 × 32 = 128D
```

另外：

```text
4 层 × 3 个 deviation statistics = 12D
4 个 scale weights              = 4D
```

总共 16D：

```python
stat_proj = nn.Sequential(
    nn.Linear(16, 32),
    nn.GELU(),
)
```

于是：

```text
128D prototype
+
32D statistics
=
160D
```

再：

```python
deg_fuse = nn.Sequential(
    nn.Linear(160, 128),
    nn.GELU(),
    nn.LayerNorm(128),
)
```

得到：

$$
z_d\in\mathbb R^{128}.
$$

---

## 9. Semantic Content Encoder

继续使用 HyperIQA 的 content-aware 思想：

```python
content_proj = nn.Sequential(
    nn.LayerNorm(content_width),
    nn.Linear(content_width, 128),
    nn.GELU(),
    nn.LayerNorm(128),
)
```

输入：

```text
global_v
```

得到：

$$
z_s\in\mathbb R^{128}.
$$

---

## 10. Degradation-Conditioned HyperNet

拼接：

$$
c=[z_s;z_d]\in\mathbb R^{256}.
$$

然后：

```python
hyper = nn.Sequential(
    nn.Linear(256, 128),
    nn.GELU(),
    nn.Linear(128, 257),
)
```

输出：

$$
[\Delta w(x),\Delta b(x)].
$$

其中：

$$
\Delta w\in\mathbb R^{256}.
$$

---

## 11. Dynamic Quality Regression

当前 static predictor 保留：

$$
q_{base}=w_0^Th_q+b_0.
$$

动态 correction：

$$
\Delta q
=
\frac{
\Delta w(x)^T LN(h_q)
}{
\sqrt{D}
}
+
\Delta b(x).
$$

最终：

$$
q=q_{base}+\Delta q.
$$

### HyperNet 最后一层也必须 zero-init

所以初始：

$$
\Delta w=0,\quad \Delta b=0,
$$

从而：

$$
q=q_{base}.
$$

Full 一开始不会破坏当前强 B1。

# 13. 为什么这两个模块都不“水”

### DG-MPQ+

它完成：

```text
multi-level representation
→ local-global deviation
→ deviation-aware scale fusion
→ patch weighting
→ degradation-aware aggregation
```

是完整的 representation-level module。

### DCAR

它完成：

```text
multi-level degradation prototype encoding
+
deviation statistics encoding
+
semantic content encoding
→ dynamic predictor generation
→ sample-specific regression correction
```

不再只是 `global_v → tiny MLP`。

所以两个模块都有明确内部机制，同时属于不同层级：

```text
DG-MPQ+ = representation level
DCAR    = prediction level
```

硬拆的问题：


容易被认为本来就是一个模块。

两者可以自然回答不同问题。

# 26. 如果成功，最终论文故事

## Contribution 1：DG-MPQ+

**Deviation-Guided Multi-Level Patch Quality Modeling**

> 利用 CLIP 多层 patch representation 建模不同语义层次的 AIGC 退化，通过局部-全局语义偏差突出异常区域，并进一步根据各层退化响应自适应调整多层特征贡献，形成 degradation-aware quality representation。

## Contribution 2：DCAR

**Degradation-Conditioned Adaptive Regression**

> 不同图像内容以及不同退化模式下，相同 feature change 对主观质量的影响并不完全一致。因此进一步构造显式 multi-level degradation profile，并结合 global semantic content 动态生成样本专属的 quality regression correction。

# 27. 面试时最好解释成两个层级

可以口述：

> 第一个模块主要解决“怎么看退化”的问题。我们利用 CLIP 不同层的局部特征，并通过局部和全局语义之间的偏差来突出可能的生成异常，同时根据不同层的退化响应自适应融合多层信息。

> 第二个模块主要解决“发现退化以后怎么打分”的问题。因为不同内容和不同退化模式对人的主观质量感知影响不同，所以我们把第一阶段得到的多层退化描述和全局内容语义结合，用一个轻量 HyperNetwork 动态调整最终的质量预测规则。

这样比：

```text
两个 patch attention module
```

更自然，也比：

```text
DG-MPQ + 一个很小的 CADR head
```

完整。

# 28. 我的最终判断

我最推荐这一版，而不是继续找陌生模块，也不是把 DG-MPQ 硬切成两个名称。

原因：

1. DG-MPQ 已经被 AIGIQA-20K 反复证明有效，不能为了结构美观把它拆坏；
2. 当前最明显的可改进点确实是固定的四层平均，因此 DASF 属于低风险、机制明确的扩展；
3. CADR 已经有弱正增益，所以第二模块不是完全从零猜；
4. CADR 当前最大的逻辑缺口正是“只看 content、不看 degradation”，而 DG-MPQ 恰好能提供这部分信息；
5. DCAR 比原 CADR 更完整，但仍然只是约几十万参数量，不会变成复杂大系统；
6. 两个模块分别位于 representation level 和 prediction level，边界清楚；
7. 如果这版仍无法让 `Full - E1` 达到约 `+0.0025~0.003`，就应接受第二模块收益不足的事实并停止搜索。

所以我建议把 V19 作为最后一次结构性实验：

```text
DG-MPQ+
   ↓
explicit multi-level degradation profile
   ↓
```
