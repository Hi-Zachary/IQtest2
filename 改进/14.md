# Joint-LoRA 最终验证实验方案

> 目标：验证当前最终模型中的 `alignment_stopgrad` 是否真的有必要。
>
> 核心问题：
>
> > 保留现有 Visual Q/K LoRA、LQEA、CSAE 全部结构不变，仅去掉 Alignment 分支的 stop-gradient，让 Quality loss 与 Alignment loss 共同更新共享 Visual LoRA，是否能在不损失 Quality 的前提下提升或保持整体性能？
>
> 基准 commit：
>
> `91c1250f0f1348d482757c72c5f899e6843b36ee`
>
> 失败候选 QARE commit：
>
> `fe88974d2ac7ceff37b619711d0248eb3b9cc39c`
>
> QARE 已明确失败，本实验不得继续修改 QARE。
>
> 本实验正常只新增 **1 次 split5 完整训练**。若结果边界模糊，最多再补 **1 次 split6**。
>
> 禁止继续搜索新模块。

# 1. 为什么要做这次实验

当前 Reference：

```text
CLIP ViT-B/16
+
Visual Q/K LoRA
+
LQEA
+
CSAE
+
Alignment Stop-Gradient
```

信息流：

```text
                 CLIP + Q/K LoRA
                        │
                adapted features
                        │
          ┌─────────────┴─────────────┐
          │                           │
          ▼                           ▼
         LQEA                    stop-gradient
          │                           │
          ▼                           ▼
      Quality Head                  CSAE
          │                           │
          ▼                           ▼
          Q                           A
```

因此：

```text
Quality loss
→ LQEA
→ Visual LoRA

Alignment loss
→ CSAE
→ Alignment Head

Alignment loss
X→ Visual LoRA
```

当前 Visual LoRA 实际主要由 Quality supervision 驱动。

# 7. Candidate 的梯度结构

Candidate：

```text
                    Q/K LoRA
                       ▲
             ┌─────────┴─────────┐
             │                   │
       Quality Loss        Alignment Loss
             │                   │
            LQEA                 CSAE
```

总损失：

$$
L=L_Q+L_A.
$$

对 Visual LoRA 参数 $\theta_L$：

$$
\nabla_{\theta_L}L
=
\nabla_{\theta_L}L_Q
+
\nabla_{\theta_L}L_A.
$$

这就是本实验真正要验证的东西。

# 10. Initial Forward Equivalence

因为 stop-gradient 只影响 backward，不影响 forward：

Reference 与 Candidate 在训练开始前应满足：

$$
Q_{ref}=Q_{cand},
$$

$$
A_{ref}=A_{cand}.
$$

要求：

$$
\max|Q_{ref}-Q_{cand}|<10^{-7},
$$

$$
\max|A_{ref}-A_{cand}|<10^{-7}.
$$

理论上应该严格为 0 或浮点误差级。

如果不一致：

> 不允许开始训练。

# 12. 建议增加一次梯度冲突诊断

这一步不需要额外训练。

分别得到 Visual LoRA 参数上的：

$$
g_Q=\nabla_{\theta_L}L_Q,
$$

$$
g_A=\nabla_{\theta_L}L_A.
$$

计算：

$$
\cos(g_Q,g_A)
=
\frac{
g_Q^\top g_A
}{
\|g_Q\|_2\|g_A\|_2+\epsilon
}.
$$

记录：

```text
lora_grad_cosine
```

解释：

```text
> 0    两任务梯度总体协同
≈ 0    两者近似正交
< 0    存在梯度冲突
```

建议在：

```text
epoch 0
epoch 5
epoch 10
```

各随机取一个 batch 记录一次。

只记录，不根据它调参。

---

# 13. 可选记录梯度范数

同时记录：

$$
R_g=
\frac{
\|g_A\|
}{
\|g_Q\|+\epsilon
}.
$$

即：

```text
alignment_to_quality_grad_ratio
```

只作为解释性 diagnostics。

如果：

$$

$$

$$
\Delta J\le-0.004,
$$

则：

# REJECT JOINT-LORA

```text

```

> Quality 与 Alignment 对共享 Visual LoRA 存在不同优化目标，联合反向传播会损害 quality-oriented visual adaptation。

此时 stop-gradient 不再是“奇怪工程技巧”，而是有实验支撑的：

```text
Gradient Isolation
```

或：

```text
Branch Decoupling
```

训练设计。

# 25. Gradient cosine 与最终结果如何解释

## 情况 1

```text
grad cosine < 0
+
Q 明显下降
```

说明：

> Alignment 与 Quality 在 Visual LoRA 上存在直接梯度冲突。

此时保留 stop-gradient 很合理。

## 情况 2

```text
grad cosine ≈ 0 或 > 0
+
性能仍下降
```

说明：

> 不一定是简单的一阶梯度冲突，也可能是两个任务长期优化方向不同。

仍以最终性能为准。

## 情况 3

```text
grad cosine > 0
+
Joint 提升
```

说明：

> Shared LoRA 联合训练是更自然的最终方案。

# 27. 对 stop-gradient 的最终定位

如果 Joint-LoRA 失败：

不要把 stop-gradient 包装成“大创新模块”。

而是定位为：

```text
Branch Decoupling
```

或：

```text
Gradient Isolation
```

属于整体双分支框架中的训练设计。

论文中一句即可：

> Since perceptual quality and semantic alignment impose different adaptation objectives on the shared visual representation, the alignment path is gradient-isolated from the visual low-rank adapter.

然后用：

```text
Joint-LoRA
vs
Quality-directed LoRA + gradient isolation
```

这组消融作为依据。

---

# 28. 如果 Joint-LoRA 成功

最终方法完全删除：

```text
alignment_stopgrad
detach
gradient isolation
```

方法变成：

```text
CLIP + Visual Q/K Low-Rank Adaptation
            │
      shared representation
            │
    ┌───────┴───────┐
    │               │
   LQEA            CSAE
    │               │
    ▼               ▼
Quality          Alignment
```

这时 Visual LoRA 可以称：

```text
Shared Visual Low-Rank Adaptation
```

但不要单独声称原创 LoRA 算法。
