# DG-MPQ 最终机制消融方案：2×2 因子实验

## 1. 目的

不再修改模型结构，只回答一个问题：

> DG-MPQ 为什么有效？

当前可靠 Full DG-MPQ 在 AIGIQA-20K 上约为：

```text
VAL MainScore ≈ 0.8832
TEST MainScore ≈ 0.8891
```

V19/V20 已经说明：继续加入 DASF、DCAR、HMQE、DCGA 等额外结构，即使机制正常激活，也没有稳定收益。

因此最终阶段只验证 DG-MPQ 中两个真正核心因素：

1. Multi-Level Patch Representation
2. Semantic Deviation-Guided Aggregation

---

## 2. 为什么推荐 2×2，而不是三档消融

如果直接做：

```text
A: H12 + Mean Pool
B: Multi-Level + Mean Pool
C: Multi-Level + Deviation Weighting
```

则 `C-B` 同时混入：

- learned patch weighting；
- semantic deviation。

无法判断提升究竟来自“学习式 patch weighting”，还是 deviation cue。

更严格的方案是保持 patch-weighting 结构完全一致，只切换两个因素：

```text
是否 Multi-Level
是否使用 Semantic Deviation
```

---

## 3. 两个实验因素

### Factor A：Patch Representation

Single-Level：

$$
P=P_{12}.
$$

Multi-Level：

$$
P=
\frac{
P_3+P_6+P_9+P_{12}
}{4}.
$$

### Factor B：Deviation Cue

统一使用：

$$
w_i=
\sigma(f_w([P_i,d_i])).
$$

No-Deviation：

$$
d_i=0.
$$

Semantic-Deviation：

$$
d_i=
1-\cos(P_i,g),
$$

其中：

$$
g=W_g(H_{12}^{CLS}).
$$

这样 No-Deviation 与 Deviation 两组除了 `d_i` 是否是真实语义偏差信息外，网络结构和参数量完全一致。

---

## 4. 四个 Variant

| Variant | Multi-Level | Semantic Deviation | 说明 |
|---|---:|---:|---|
| A | × | × | H12 + learned patch weighting |
| B | × | ✓ | H12 + deviation-guided weighting |
| C | ✓ | × | Multi-level + learned patch weighting |
| D | ✓ | ✓ | 完整 DG-MPQ |

其中 D 就是当前已经验证有效的 DG-MPQ。

因此只需要新跑 A/B/C，三张 GPU 正好。

## 5. 各 Variant 的 forward

### A：Single-Level + No-Deviation

```python
P = P12
d = torch.zeros_like(P[..., :1])

weight_input = torch.cat([P, d], dim=-1)
w = torch.sigmoid(self.patch_weight(weight_input))

q_local = (w * P).sum(dim=1) / (w.sum(dim=1) + 1e-6)
```

### B：Single-Level + Semantic Deviation

```python
P = P12

d = 1.0 - cosine(P, g)

weight_input = torch.cat([P, d], dim=-1)
w = torch.sigmoid(self.patch_weight(weight_input))

q_local = (w * P).sum(dim=1) / (w.sum(dim=1) + 1e-6)
```

### C：Multi-Level + No-Deviation

```python
P = (P3 + P6 + P9 + P12) / 4.0
d = torch.zeros_like(P[..., :1])

weight_input = torch.cat([P, d], dim=-1)
w = torch.sigmoid(self.patch_weight(weight_input))

q_local = (w * P).sum(dim=1) / (w.sum(dim=1) + 1e-6)
```

### D：Full DG-MPQ

```python
P = (P3 + P6 + P9 + P12) / 4.0

d = 1.0 - cosine(P, g)

weight_input = torch.cat([P, d], dim=-1)
w = torch.sigmoid(self.patch_weight(weight_input))

q_local = (w * P).sum(dim=1) / (w.sum(dim=1) + 1e-6)
```

后续完全一致：

```text
q_local
→ quality_out
→ delta_q
→ v0 + tanh(lambda_q) * delta_q
→ quality fusion
→ MOS
```

## 6. 四个核心效应

Multi-Level 在无 deviation 时：

$$
\Delta_{ML}^{base}=C-A.
$$

Multi-Level 在 deviation guidance 下：

$$
\Delta_{ML}^{dev}=D-B.
$$

Semantic Deviation 在单层时：

$$
\Delta_{Dev}^{single}=B-A.
$$

Semantic Deviation 在 multi-level 时：

$$
\Delta_{Dev}^{multi}=D-C.
$$

最关键的是：

$$
D-C.
$$

它几乎纯粹回答：

> 在最终 multi-level representation 上，semantic deviation 是否真的比普通 learned patch weighting 更有效？

---

## 7. 交互效应

还可以计算：

$$
I=(D-C)-(B-A).
$$

等价于：

$$
I=(D-B)-(C-A).
$$

如果：

$$
I>0,
$$

说明 multi-level representation 与 semantic deviation 之间存在正互补。

例如：

```text
A = 0.876
B = 0.878
C = 0.879
D = 0.883
```

则：

```text
Deviation @ Single = +0.002
Deviation @ Multi  = +0.004
```

说明 multi-level representation 为 semantic deviation 提供了更合适的局部质量空间。

---

## 8. 代码实现原则

不要复制四套模块。

在当前最简单的 `dg_mpq.py` 上加入：

```python
use_multilevel=True
use_deviation=True
```

forward：

```python
P3 = ...
P6 = ...
P9 = ...
P12 = ...

if self.use_multilevel:
    P = (P3 + P6 + P9 + P12) / 4.0
else:
    P = P12
```

然后：

```python
if self.use_deviation:
    d = 1.0 - cosine(P, g)
else:
    d = torch.zeros(
        P.shape[0],
        P.shape[1],
        1,
        device=P.device,
        dtype=P.dtype,
    )
```

其余完全相同：

```python
weight_input = torch.cat([P, d], dim=-1)
w = torch.sigmoid(self.patch_weight(weight_input))
```

这样 A/B/C/D：

```text
参数量一致
patch-weight MLP 一致
quality_out 一致
```

只改变实际信息流。

## 14. 怎样判断两个机制都成立

理想例子：

```text
A = 0.8765
B = 0.8790
C = 0.8795
D = 0.8832
```

得到：

```text
Multi-Level @ Base = +0.0030
Multi-Level @ Dev  = +0.0042

Deviation @ Single = +0.0025
Deviation @ Multi  = +0.0037
```

这时可以很有底气地说：

> Multi-level representation 与 semantic deviation guidance 都具有稳定的独立价值，并且存在互补。

---

## 15. 如果 Multi-Level 几乎无效

例如：

```text
C-A ≈ 0
D-B ≈ 0
```

但：

```text
D-C 明显 > 0
```

则不要把 Multi-Level 单独包装成贡献。

真正核心是：

```text
Semantic Deviation-Guided Aggregation
```

Multi-level 只作为实现细节。

---

## 16. 如果 Deviation 几乎无效

例如：

```text
D-C ≈ 0
B-A ≈ 0
```

则说明 DG-MPQ 的收益主要来自：

```text
multi-level representation
+
learned patch weighting
```

而不是 deviation cue。

论文故事应据此调整。

---

## 17. 如果只有组合才有效

若：

```text
B-A ≈ 0
C-A ≈ 0
D-A 明显 > 0
```

则不要强行写成两个独立模块。

应该强调：

> multi-level representation 与 semantic deviation 是两个 coupled components，只有组合后才形成有效的 degradation-aware representation。

这种结果同样是合理的。

---

## 18. 是否需要补 Mean Pool baseline

第一轮不用。

如果 A/B/C/D 结果清晰，正式论文阶段可以额外补：

```text
Multi-Level + Mean Pool
```

回答：

> learned patch weighting 本身是否优于 uniform aggregation？

但它不是当前最核心的问题。

## 20. 最后停止规则

这轮实验完成后：

> 不再改网络结构。

根据 A/B/C/D 结果决定最终论文怎么写：

- 两个因素都有效：`DG-MPQ = MLQR + SDGA`
- 只有一个有效：只重点强调那个机制
- 只有组合有效：把 DG-MPQ 作为 coupled module
- 都没有明显独立作用：保持 DG-MPQ 作为整体模块，不再拆贡献

当前最重要的任务已经从：

```text
“再找一个更复杂的模块”
```

转变为：

```text
“解释唯一稳定有效的 DG-MPQ 到底为什么有效”
```

这会比继续设计 V21/V22 更有研究价值。
