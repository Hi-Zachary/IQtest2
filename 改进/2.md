# V15 改进方案：PTLC Prompt-Token Late-interaction Calibration

> 当前分支：`v14`
>
> 当前参考 commit：`883642ed25934bcdaf550e574648ebebc8c0147b`

## 1. 当前结论

V14 已经把问题定位得很干净：

```text
R0       A-SRCC = 0.7327
B2-MSRC  A-SRCC = 0.7007
```

同时 matched-init + stop-gradient 已验证：

```text
Full-Q == B1-Q
```

逐 epoch 可以完全一致。

因此 V15 不再继续修 MSCM/MSRC，也不再围绕 Full 的 Quality 做优化；新的目标只有一个：

> 找到一个真正能独立提高 Alignment 的第二模块。

前面几代失败的共同点：

```text
HCMI：cross-attention 太重
TCAP：global query 对 patch attention 接近均匀
MSCM：global text → patch similarity map，增益极小
MSRC：mean-pooled visual + global text relation，直接负贡献
```

所以 V15 改成另一种范式：

```text
保留 prompt token
+
保留 image patch
+
不使用 cross-attention
+
直接在 CLIP 已训练好的 shared space 中做 late interaction
```

---

# 2. 第二贡献：PTLC

暂定名：

**PTLC — Prompt-Token Late-interaction Calibration**

三阶段：

```text
1. Multi-Level Token Projection
        ↓
2. Bidirectional Prompt-Patch Late Interaction
        ↓
3. Coverage-Consistency Calibration
        ↓
Alignment Residual
```

和 DG-MPQ 形成对称：

```text
DG-MPQ
Multi-Level Patch Representation
→ Local-Global Deviation
→ Deviation-Guided Aggregation

PTLC
Multi-Level Token Representation
→ Prompt-Patch Late Interaction
→ Coverage-Consistency Calibration
```

---

# 5. Stage 1：Multi-Level Token Projection

## 5.1 Visual patch tokens

输入：

```text
H9  : [B,197,768]
H12 : [B,197,768]
```

去 CLS：

```python
p9 = h9[:, 1:, :]
p12 = h12[:, 1:, :]
```

得到：

```text
[B,196,768]
```

不要再学习新的 `Linear(768,256)` 作为跨模态空间。

直接复用冻结 CLIP 的：

```text
visual_projection: 768 -> 512
```

即：

```python
V9 = visual_projection(p9)
V12 = visual_projection(p12)
```

得到：

```text
[B,196,512]
```

随后：

```python
V9 = F.normalize(V9, dim=-1)
V12 = F.normalize(V12, dim=-1)
```

## 5.2 Text tokens

当前：

```text
text_tokens: [B,77,512]
```

直接使用冻结 CLIP：

```python
T = text_projection(text_tokens)
T = F.normalize(T, dim=-1)
```

得到：

```text
[B,77,512]
```

核心原则：

> 不再要求 AGIQA-3K 自己重新学习一个 image-text shared embedding space。

# 7. Stage 2：Bidirectional Prompt-Patch Late Interaction

## 7.1 Similarity matrix

H9：

$$
S_9 = T V_9^T
$$

实现：

```python
S9 = torch.einsum("btd,bpd->btp", T, V9)
```

形状：

```text
[B,T,196]
```

H12 同理：

```python
S12 = torch.einsum("btd,bpd->btp", T, V12)
```

# 8. Text-to-Image MaxSim

对于每个 prompt token：

$$
m^{T\rightarrow I}_{9,j}
=
\max_i S_{9,j,i}
$$

实现：

```python
m9_t = S9.max(dim=-1).values
m12_t = S12.max(dim=-1).values
```

形状：

```text
[B,T]
```

含义：

> prompt 中每个 token 是否能在图像中找到一个足够匹配的视觉 patch。

这是 V15 的核心 correspondence。

---

# 9. Image-to-Text MaxSim

先 mask invalid token：

```python
S9m = S9.masked_fill(
    ~valid_mask.unsqueeze(-1),
    -1e4,
)

S12m = S12.masked_fill(
    ~valid_mask.unsqueeze(-1),
    -1e4,
)
```

然后：

```python
m9_v = S9m.max(dim=1).values
m12_v = S12m.max(dim=1).values
```

得到：

```text
[B,196]
```

含义：

> image patch 是否能被 prompt 中至少一个有效 token 解释。

# 10. Multi-Level Consistency

文本方向：

$$
\bar m_t
=
\frac{m9_t+m12_t}{2}
$$

$$
d_t
=
|m9_t-m12_t|
$$

视觉方向：

$$
\bar m_v
=
\frac{m9_v+m12_v}{2}
$$

目的：

> 同一个 correspondence 如果在 H9 和 H12 都稳定出现，则更可信。

---

# 11. Stage 3：Coverage-Consistency Calibration

Alignment 不能只看平均 similarity。

例如：

```text
"a dog wearing a red hat"
```

可能：

```text
dog      0.90
wearing  0.76
red      0.82
hat      0.22
```

平均分仍不算低，但关键语义 `hat` 缺失，Alignment 应该明显下降。

因此显式建模：

```text
整体 semantic coverage
+
最弱 semantic coverage
+
跨层 consistency
```

---

# 12. Token reliability weighting

每个 token 构造：

```text
[
T_j,
m9_t_j,
m12_t_j,
|m9_t_j-m12_t_j|
]
```

维度：

```text
512 + 3 = 515
```

权重网络：

```text
Linear(515,128)
→ GELU
→ Linear(128,1)
```

实现：

```python
token_feat = torch.cat([
    T,
    m9_t.unsqueeze(-1),
    m12_t.unsqueeze(-1),
    d_t.unsqueeze(-1),
], dim=-1)

token_logits = self.token_weight(
    token_feat
).squeeze(-1)

token_logits = token_logits.masked_fill(
    ~valid_mask,
    -1e4,
)

token_weight = F.softmax(
    token_logits,
    dim=-1,
)
```

---

# 13. Semantic Coverage

$$
s_{cov}
=
\sum_j
w_j \bar m_{t,j}
$$

实现：

```python
s_cov = (
    token_weight * m_t
).sum(dim=-1, keepdim=True)
```

---

# 14. Weak Semantic Coverage

显式看最低匹配的若干有效 token。

建议：

```text
bottom_k = 3
```

$$
s_{weak}
=
\operatorname{Mean}
\left(
\operatorname{BottomK}(\bar m_t)
\right)
$$

注意：

> Bottom-K 必须只在有效文本 token 中计算，不能把 padding 混进去。

推荐逐样本实现，保证短 prompt 也安全。

---

# 15. Cross-Level Consistency

$$
s_{cons}
=
1-
\sum_j w_j d_{t,j}
$$

实现：

```python
s_cons = 1.0 - (
    token_weight * d_t
).sum(dim=-1, keepdim=True)
```

# 16. Visual-side Coverage

$$
m_v = \frac{m9_v+m12_v}{2}
$$

提取：

```python
s_v_mean = m_v.mean(dim=-1, keepdim=True)
s_v_max = m_v.max(dim=-1, keepdim=True).values
```

第一版不再给 patch 额外训练一套 weighting network。

保留原始 global correspondence：

# 20. 不再重写 Alignment baseline

这是 V15 相比 MSRC 最重要的结构改变之一。

先保留 R0 Alignment baseline：

```python
v_a = alignment_visual_proj(global_v)
t_a = alignment_text_proj(global_t)

h0_a = alignment_base_fusion(
    torch.cat([v_a, t_a], dim=-1)
)
```

然后：

$$
h_a
=
h_{0,a}
+
\tanh(\lambda_a)\delta_a
$$

其中：

```text
lambda_a init = 0.01
```

最后：

```python
a = align_head(h_a)
```

目的：

> 新模块只作为 residual 补充 fine-grained alignment 信息，而不是替换一个已经很强的 R0 representation。

# 23. `ptlc.py` 推荐结构

```python
import torch
import torch.nn as nn
import torch.nn.functional as F


class PTLC(nn.Module):

    def __init__(
        self,
        text_width=512,
        dim=256,
        bottom_k=3,
    ):
        super().__init__()

        self.bottom_k = bottom_k

        self.token_weight = nn.Sequential(
            nn.Linear(text_width + 3, 128),
            nn.GELU(),
            nn.Linear(128, 1),
        )

        self.out_proj = nn.Sequential(
            nn.Linear(text_width + 6, dim),
            nn.GELU(),
            nn.LayerNorm(dim),
        )

        self._last_stats = None


    def forward(
        self,
        v9,
        v12,
        text_tokens,
        text_mask,
        global_v,
        global_t,
    ):

        V9 = F.normalize(v9, dim=-1)
        V12 = F.normalize(v12, dim=-1)
        T = F.normalize(text_tokens, dim=-1)

        valid = text_mask.bool().clone()
        valid[:, 0] = False

        # late interaction
        S9 = torch.einsum(
            "btd,bpd->btp",
            T,
            V9,
        )

        S12 = torch.einsum(
            "btd,bpd->btp",
            T,
            V12,
        )

        # text -> image
        m9_t = S9.max(dim=-1).values
        m12_t = S12.max(dim=-1).values

        # image -> text
        S9m = S9.masked_fill(
            ~valid.unsqueeze(-1),
            -1e4,
        )

        S12m = S12.masked_fill(
            ~valid.unsqueeze(-1),
            -1e4,
        )

        m9_v = S9m.max(dim=1).values
        m12_v = S12m.max(dim=1).values

        m_t = 0.5 * (m9_t + m12_t)
        d_t = torch.abs(m9_t - m12_t)

        m_v = 0.5 * (m9_v + m12_v)

        # token reliability
        token_feat = torch.cat([
            T,
            m9_t.unsqueeze(-1),
            m12_t.unsqueeze(-1),
            d_t.unsqueeze(-1),
        ], dim=-1)

        token_logits = self.token_weight(
            token_feat
        ).squeeze(-1)

        token_logits = token_logits.masked_fill(
            ~valid,
            -1e4,
        )

        token_w = F.softmax(
            token_logits,
            dim=-1,
        )

        s_cov = (
            token_w * m_t
        ).sum(
            dim=-1,
            keepdim=True,
        )

        s_cons = 1.0 - (
            token_w * d_t
        ).sum(
            dim=-1,
            keepdim=True,
        )

        t_cov = torch.einsum(
            "bt,btd->bd",
            token_w,
            T,
        )

        # bottom-k should be computed only on valid tokens
        weak_scores = []

        for b in range(m_t.size(0)):
            vals = m_t[b][valid[b]]

            k = min(
                self.bottom_k,
                vals.numel(),
            )

            if k == 0:
                weak = m_t.new_zeros(())
            else:
                weak = torch.topk(
                    vals,
                    k=k,
                    largest=False,
                ).values.mean()

            weak_scores.append(weak)

        s_weak = torch.stack(
            weak_scores
        ).unsqueeze(-1)

        s_v_mean = m_v.mean(
            dim=-1,
            keepdim=True,
        )

        s_v_max = m_v.max(
            dim=-1,
            keepdim=True,
        ).values

        gv = F.normalize(
            global_v,
            dim=-1,
        )

        gt = F.normalize(
            global_t,
            dim=-1,
        )

        s_global = (
            gv * gt
        ).sum(
            dim=-1,
            keepdim=True,
        )

        desc = torch.cat([
            t_cov,
            s_cov,
            s_weak,
            s_cons,
            s_v_mean,
            s_v_max,
            s_global,
        ], dim=-1)

        delta_a = self.out_proj(desc)

        entropy = (
            -token_w
            * torch.log(
                token_w + 1e-8
            )
        ).sum(dim=-1).mean()

        self._last_stats = {
            "coverage":
                round(s_cov.mean().item(), 4),

            "weak_coverage":
                round(s_weak.mean().item(), 4),

            "consistency":
                round(s_cons.mean().item(), 4),

            "global_cos":
                round(s_global.mean().item(), 4),

            "token_w_entropy":
                round(entropy.item(), 4),

            "token_w_max":
                round(
                    token_w.max(
                        dim=-1
                    ).values.mean().item(),
                    4
                ),
        }

        return delta_a
```

# 47. 最终方法叙事

## Quality：DG-MPQ

AIGC perceptual degradation 往往表现为局部视觉内容相对整体语义出现异常偏离，因此：

```text
multi-level patches
→ local-global deviation
→ deviation-guided aggregation
```

## Alignment：PTLC

AIGC image-text alignment 不是一个单纯 global similarity 问题。

一个 prompt 往往包含：

```text
objects
attributes
relations
scene semantics
```

即使 global similarity 很高，也可能有少数关键语义没有被生成。

因此：

```text
prompt tokens
+
image patches
→ late interaction
→ semantic coverage
→ weakest semantic coverage
→ cross-level consistency
```

最终两个贡献形成：

```text
DG-MPQ：
局部视觉异常

PTLC：
细粒度 prompt 语义覆盖
```

# 48. 一句话总结

V15 不再使用 pooled global text 去重新学习 Alignment representation，而是直接利用 CLIP 已预训练的 token-patch shared space：

```text
H9/H12 patches
+
prompt tokens
→ bidirectional MaxSim
→ semantic coverage
→ weakest semantic coverage
→ cross-level consistency
→ lightweight alignment residual
```

并通过：

$$
h_a
=
h_{0,a}
+
\tanh(\lambda_a)\delta_a
$$

保护现有强 R0 baseline。

第一轮只跑 B2。若 PTLC 不能把 A-SRCC 从约 `0.7327` 提升到至少 `0.738~0.740`，则直接停止，不再继续修这一类 Alignment representation。
