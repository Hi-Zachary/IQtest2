## 1. 先纠正上一版方案

上一版把 HyperIQA 简化成：

$$
[\gamma,\beta]=g(h_q),
$$

$$
h'_q=\gamma\odot h_q+\beta.
$$

这个结构本身可以工作，但它更接近：

```text
FiLM / feature modulation / adaptive affine calibration
```

而不是 HyperIQA 原论文真正的核心。

HyperIQA 原论文采用的是：

```text
semantic/content feature
        ↓
Hyper Network
        ↓
生成 Target Quality Network 的 weights + biases
        ↓
Target Network
        ↓
quality score
```

官方实现中，HyperNet 会为每张图像生成多个 fully-connected layer 的权重和偏置，再由 TargetNet 使用这些**样本专属参数**完成质量预测。

所以如果我们说“借鉴 HyperIQA 的成熟模块”，至少应该保留：

> **content-conditioned dynamic predictor parameters**

而不应该只做 `γ/β` feature modulation。

---

## 2. 为什么现在 HyperIQA 方向比 QARD/DAPS 更合理

当前已经验证失败的模块包括：

```text
DAPS: patch score + patch importance
QARD: quality query + patch retrieval
TCAP: patch attention
MSCM: patch-text similarity map
MSRC/PTLC: cross-modal relation
```

这些模块虽然形式不同，但大量操作仍发生在：

```text
patch representation
patch selection
patch relation
```

而 DG-MPQ 已经完成：

```text
H3/H6/H9/H12
        ↓
multi-level patch representation
        ↓
local-global deviation
        ↓
patch weighting
        ↓
degradation-aware representation
```

因此继续做 patch 模块，很容易重复回答：

> 哪些局部区域对质量重要？

这已经出现明显的信息饱和。

---

## 3. 第二模块应该解决另一个问题

DG-MPQ 解决：

> **图像中哪些局部退化应该被强调？**

它属于：

```text
representation-level quality modeling
```

而 HyperIQA 的核心问题是：

> **面对不同内容的图像，是否应该使用完全相同的质量映射函数？**

例如：

```text
天空
人脸
文字
动物毛发
建筑纹理
抽象绘画
```

即使得到相似的质量 feature，不同内容对 blur、texture loss、structure artifact 等退化的敏感程度也可能不同。

因此第二模块应作用在：

```text
quality representation
        ↓
quality prediction rule
```

而不是重新提取 patch feature。

---

## 4. 与当前框架的自然对应

HyperIQA 把 IQA 过程分成：

```text
1. Content Understanding
2. Perception Rule Learning
3. Quality Prediction
```

当前模型可以对应为：

```text
CLIP global visual feature
        ↓
Content Understanding
        ↓
CADR Hyper Network
        ↓
dynamic quality rule

同时：

CLIP multi-level patches
        ↓
DG-MPQ
        ↓
degradation-aware quality feature
        ↓
dynamic quality rule
        ↓
MOS
```

所以两个模块职责是：

```text
DG-MPQ:
“What degradation evidence exists?”

CADR:
“How should this content map degradation evidence to quality?”
```

这是机制层面真正不同的两个问题。

---

## 5. 为什么不照搬原 HyperIQA 的 5 层动态 TargetNet

原 HyperIQA 使用 ResNet50 + local distortion-aware features + HyperNet + 多层动态 TargetNet。

如果直接照搬到当前 `h_q=256D` 的 CLIP 框架，会有三个问题。

### 5.1 参数自由度过大

每张图动态生成整套多层 MLP 参数会产生大量 sample-specific weights，而当前 `h_q` 已经是高层融合表征，没有必要重新建立很深的动态网络。

### 5.2 会破坏强 baseline

当前 B1 已经达到：

```text
AIGIQA-20K TEST MainScore = 0.8887
```

直接用随机初始化的动态 MLP 替换现有质量头，会把有效 baseline 一起改掉，不适合 controlled ablation。

### 5.3 原论文 local distortion module 已被 DG-MPQ 替代

HyperIQA 自身也有 local distortion-aware modeling，而当前 DG-MPQ 已经承担这部分职责。

所以这里只迁移 HyperIQA 的：

```text
content-adaptive prediction rule
```

---

## 6. 最终推荐模块：CADR

建议名称：

**CADR — Content-Adaptive Dynamic Regressor**

定位：

```text
HyperIQA-style lightweight dynamic quality predictor
```

不要声称是“完整 HyperIQA”，正确表述是：

> Inspired by the content-adaptive quality prediction principle of HyperIQA, we introduce a lightweight dynamic regression mechanism adapted to CLIP-based AIGC quality assessment.

## 7. CADR 总体结构

当前 B1：

```text
global_v
   ↓
quality_visual_proj
   ↓
v0_q
   ↓
DG-MPQ
   ↓
v_q
   │
global_t
   ↓
t_q
   │
[v_q,t_q]
   ↓
quality_fusion
   ↓
h_q
   ↓
static quality_head
   ↓
q_base
```

加入 CADR：

```text
                    global_v
                        │
                Content Projector
                        │
                     c_sem
                        │
                   HyperNet
                        │
                Δw(x), Δb(x)
                        │
                        ▼
h_q ─────────────── Dynamic Regressor
 │                      │
 │                      ▼
 └→ static head       Δq(x)
        │                │
        ▼                │
     q_base ─────────────┘
             │
             ▼
        q = q_base + Δq
```

---

## 8. Conditioner 和 target feature 必须分开

这是本方案最关键的设计。

不要：

```text
h_q → HyperNet → dynamic weights → h_q
```

这样容易退化成普通 MLP。

推荐：

### HyperNet conditioner

使用：

```text
global_v
```

即 CLIP 的高层全局视觉语义，更接近 HyperIQA 的 semantic/content feature。

### Dynamic regressor input

使用：

```text
h_q
```

即：

```text
DG-MPQ-enhanced visual feature
+
global text feature
→ quality_fusion
```

因此：

```text
Content feature ≠ Quality feature
```

角色明确分离。

---

## 9. 为什么 conditioner 第一版只用 global_v

不要输入 H9/H12/patch map/DG patch weight，否则 CADR 又变回 patch modeling。

第一版也不加入 `global_t`。AIGIQA-20K 的 overall MOS 虽然包含 text-image alignment，但 `h_q` 本身已经融合 `v_q + t_q`。

如果 HyperNet conditioner 再使用 `global_t`，容易学到 prompt-specific shortcut。

所以第一版坚持：

```text
visual semantic content → prediction rule
```

文本仍通过 `h_q` 影响最终 MOS。

---

## 10. CADR 只生成最终动态回归参数

本方案只动态生成：

```text
Δw(x) ∈ R^256
Δb(x) ∈ R
```

原静态预测器：

$$
q_{base}=w_0^T h_q+b_0.
$$

HyperNet：

$$
c=P_c(g_v),
$$

$$
[\Delta w(x),\Delta b(x)]=H(c).
$$

动态 residual：

$$
\Delta q(x)=\frac{\Delta w(x)^T\hat h_q}{\sqrt D}+\Delta b(x),
$$

其中：

$$
\hat h_q=\operatorname{LN}(h_q),\quad D=256.
$$

最终：

$$
q=q_{base}+\Delta q(x).
$$

---

## 11. 为什么采用 Residual Dynamic Head

不直接用动态头完全替换 `quality_head`，而保留：

```text
strong static baseline
+
sample-specific residual correction
```

CADR 的任务是：

> 根据图像内容，对现有质量映射做 image-specific correction。

这比“重新学习整套预测规则”更稳，也更适合当前强 baseline。

---

## 12. 不使用 λ gate，改用 zero-init

QARD/DAPS 之前采用：

```text
tanh(lambda) * residual
```

虽然稳定，但新模块容易被 scalar gate 长期压得很小。

CADR 不再增加 outer scalar gate。

改成：

> **HyperNet 最后一层 zero initialization。**

训练开始时：

```text
Δw = 0
Δb = 0
```

因此：

```text
q == q_base
```

也就是说 Full 在初始化时与 B1 的函数完全一致。

---

## 13. 推荐实现

新增：

```text
v8/ipiqa/models/cadr.py
```

```python
import math
import torch
import torch.nn as nn


class CADR(nn.Module):
    def __init__(self, content_width, dim=256, hidden=128):
        super().__init__()

        self.content_proj = nn.Sequential(
            nn.LayerNorm(content_width),
            nn.Linear(content_width, hidden),
            nn.GELU(),
            nn.LayerNorm(hidden),
        )

        self.hyper = nn.Sequential(
            nn.Linear(hidden, hidden),
            nn.GELU(),
            nn.Linear(hidden, dim + 1),
        )

        self.target_norm = nn.LayerNorm(dim)

        # Initial Full function == B1 function
        nn.init.zeros_(self.hyper[-1].weight)
        nn.init.zeros_(self.hyper[-1].bias)

        self._last_stats = None

    def forward(self, global_v, h_q):
        c = self.content_proj(global_v)
        params = self.hyper(c)

        delta_w = params[:, :-1]
        delta_b = params[:, -1:]

        z = self.target_norm(h_q)

        delta_q = (
            (delta_w * z).sum(dim=-1, keepdim=True)
            / math.sqrt(z.shape[-1])
            + delta_b
        )

        with torch.no_grad():
            self._last_stats = {
                "dw_norm": delta_w.norm(dim=-1).mean().item(),
                "dw_batch_std": delta_w.std(dim=0).mean().item(),
                "db_abs": delta_b.abs().mean().item(),
                "delta_abs": delta_q.abs().mean().item(),
                "content_norm": c.norm(dim=-1).mean().item(),
            }

        return delta_q
```

```python

v0_q = self.quality_visual_proj(global_v)

    delta_q = self.dg_mpq(
```

## 20. 为什么现在不做 distribution modeling

Distribution learning 是成熟 IQA 方向，但当前 AIGIQA-20K 实验接口主要使用 MOS。

如果没有稳定、完整、可复现的 individual-rating histogram/variance，强行构造 distribution target 会引入额外监督假设。

而且它更接近 loss/supervision 方向，不是当前希望寻找的成熟结构模块。

所以第一优先级仍是 CADR。

## 21. 为什么不选 DBCNN / TOPIQ / DEIQT

### DBCNN

主要还是 representation-level bilinear/distortion feature interaction，与 DG-MPQ 更重叠。

### TOPIQ

包含跨尺度和 top-down spatial interaction，仍大量操作 local/spatial feature。

### DEIQT

已经通过 QARD 路线实质验证了 `quality query → patch retrieval`，AIGIQA-20K 上无额外收益。

因此不再尝试。

## 28. 为什么 dw_batch_std 很重要

HyperIQA 的核心是：

> 不同图像生成不同 predictor。

如果：

```text
dw_batch_std ≈ 0
```

说明 CADR 退化成所有样本共享同一套额外权重，本质只是 another static head。

这意味着机制没有真正成立。

---

## 29. 机械激活与任务收益要分开判断

### 情况 A：动态权重有明显变化，指标也涨

```text
dw_batch_std > 0
Full > B1
```

这是理想情况。

### 情况 B：动态权重明显变化，但 Full ≈ B1

说明：

> content-adaptive predictor 确实工作了，但没有提供有效新信息。

直接停止，不增加 HyperNet 深度。

### 情况 C：动态权重长期接近 0

先检查 gradient / optimizer / zero-init。

如果梯度正常但模型仍主动把动态权重压回 0，则说明 baseline 不需要它，也应停止。

## 34. 方案审查：为什么我认为它比上一版合理

### 合理点 1：论文依据对应正确

HyperIQA 的核心确实是：

```text
semantic feature
→ hypernetwork
→ sample-specific predictor parameters
```

CADR 保留了这一点。

### 合理点 2：与 DG-MPQ 职责不同

```text
DG-MPQ = degradation representation
CADR   = prediction-rule adaptation
```

没有明显 patch-level 重复。

### 合理点 3：不破坏 B1

```text
q = q_base + zero-init dynamic residual
```

Full 从与 B1 完全相同的函数开始训练，controlled ablation 更干净。

### 合理点 4：参数量很小

约 `0.1M`，不会只是靠堆大量参数获得微小提升。

### 合理点 5：AIGIQA-20K 适合检验 content adaptation

20K 图像、15 个生成模型和更丰富内容，比 AGIQA-3K 更适合检验 content-dependent prediction rule。

## 35. 这个方案仍然有哪些风险

### 风险 1：CLIP 可能已经隐式实现 content adaptation

`h_q` 本身来源于强语义 backbone，因此固定 Linear head 也可能已经足够利用 content information。

如果如此，CADR 仍然不会涨。

### 风险 2：baseline 已经很强

当前 test MainScore 约 0.889，不能期待轻量模块必然带来 `+0.01`。

### 风险 3：可能学习 generator/content shortcut

CADR 可能通过 global_v 识别生成器或内容类型，然后直接学 score bias。

如果 CADR 成功，后续应再看 generator-wise performance 或 cross-dataset generalization，但第一轮不要改变训练。

---

## 36. 如果 CADR 成功，两个贡献如何组织

### Contribution 1 — DG-MPQ

**Deviation-Guided Multi-Level Patch Quality Modeling**

```text
bottom-up local degradation modeling
```

### Contribution 2 — CADR

**Content-Adaptive Dynamic Regression**

```text
content-aware sample-specific quality mapping
```

组合逻辑：

```text
Local degradation evidence
        ↓
DG-MPQ
        ↓
quality representation
        ↓
CADR conditioned by global semantics
        ↓
content-adaptive quality mapping
        ↓
MOS
```

一句话：

> DG-MPQ determines what degradation evidence should be emphasized, while CADR determines how the degradation-aware representation should be mapped to subjective quality under different image contents.

## 37. 如果 CADR 失败，应该接受什么结论

如果在 AIGIQA-20K 上：

```text
DG-MPQ + CADR ≈ DG-MPQ
```

那么建议正式接受：

> 当前 CLIP + DG-MPQ 已经编码了绝大部分该 benchmark 可利用的质量信息，额外 feature module 或 adaptive prediction module 的边际收益不足以支撑第二个独立结构贡献。

此后不再继续寻找第三、第四个成熟 IQA 模块。

## 41. 最终决策规则

### 保留 CADR

要求：

```text
VAL:
Full - B1 >= +0.003

并且 TEST:
Full - B1 > 0
```

最好 test：

```text
>= +0.002
```

### 边缘

```text
VAL +0.001 ~ +0.003
```

只允许补一个 seed，不改结构。

### 放弃

```text
VAL < +0.001
```

或：

```text
TEST <= 0
```

直接放弃 CADR，并结束第二模块搜索。

## 42. 最终判断

这次方案比上一版 `γ/β Hyper Calibration` 更合理，原因是：

1. 真正保留 HyperIQA 的核心机制：**动态生成样本专属 prediction parameters**；
2. 不再和 DG-MPQ 做重复的 patch/local modeling；
3. 使用固定 B1 + zero-init dynamic residual，不破坏已有强 baseline；
4. 只有约 0.1M 参数，不靠堆容量；
5. AIGIQA-20K 的内容和生成分布更丰富，适合检验 content-adaptive mapping；
6. 如果仍失败，就有足够证据停止第二模块搜索。

因此，这次不是“再随便找一个模块试试”，而是在已经排除 patch-level / alignment-level 增强后，基于成熟 IQA 文献，选择一个机制维度真正不同的最后候选。

如果它仍没有稳定收益，就应该接受模型饱和的实验事实，而不是继续堆模块。
