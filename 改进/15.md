# AIGIQA-20K No-Stop Joint Training 最终验证方案

> 目标：在 AIGIQA-20K 上采用标准 joint backpropagation，彻底取消 stop-gradient，并验证当前两个核心模块 LQEA 与 CSAE 是否对统一的 Overall MOS 预测真实有效。
>
> 本轮不再比较 stop-gradient / no-stop，也不再搜索新模块。

## 1. 数据集与任务

使用 AIGIQA-20K：

```text
Total = 20,000
Train = 14,000
Val   = 2,000
Test  = 4,000
```

每张图像有对应 prompt。该数据集只有一个 Overall MOS，主观评分综合考虑 perceptual quality 与 text-image alignment。

因此本轮不输出两个独立分数，而是：

```text
Image + Prompt
      ↓
CLIP + Visual Q/K LoRA
      ↓
LQEA + CSAE
      ↓
MOS Fusion
      ↓
Overall MOS
```

## 2. 最终训练原则：不使用 stop-gradient

新模型中直接采用标准计算图：

```text
MOS Loss
   │
   ├──→ Overall Fusion / Head
   ├──→ LQEA
   ├──→ CSAE
   └──→ Visual Q/K LoRA
```

要求：

```text
alignment_stopgrad = False
```

更建议在 AIGIQA-20K 新模型里直接删除 `alignment_stopgrad` 配置和所有 `.detach()`。

Text Encoder 仍冻结。

## 3. Backbone 固定

保持当前已验证设置：

```text

Visual LoRA target = q_proj, k_proj
rank = 4

```

冻结：

```text

CLIP text encoder
visual projection

```

只训练视觉 Q/K LoRA。

禁止扩大 rank、增加 V/O LoRA、增加 text LoRA 或 full fine-tuning。

## 5. Shared Representation

CLIP 输出：

```text
global_v
global_t
H3
H6
H9
H12
text_tokens
attention_mask
```

公共投影：

$$
v_0=f_v(g_v),\qquad
t_0=f_t(g_t),
$$

其中 $v_0,t_0\in\mathbb R^{256}$。

建议新模型统一命名：

```python
self.visual_proj
self.text_proj
```

不要再使用 quality/alignment 两套重复的 global projection。

## 6. LQEA 保持当前机制

完全继承当前 clean LQEA：

$$
P_l=W_l(\operatorname{LN}(H_l)),
\quad l\in\{3,6,9,12\},
$$

$$
P=\frac{P_3+P_6+P_9+P_{12}}{4},
$$

$$
w_i=\sigma(f_w(P_i)),
$$

$$
q_e=
\frac{\sum_iw_iP_i}
{\sum_iw_i+\epsilon},
$$

$$
\Delta v_q=f_q(q_e),
$$

$$
v_q=v_0+\tanh(\gamma_q)\Delta v_q.
$$

关闭 LQEA 时：

$$
v_q=v_0.
$$

不改变 LQEA 内部结构。

## 7. CSAE 保持当前机制

继续使用当前 `global_local` 完整版本。

Global alignment：

$$
s_g=\cos(g_v,g_t).
$$

文本 token 分组：

$$
t_k=
\operatorname{Norm}
\left(
\frac{1}{|F_k|}
\sum_{j\in F_k}T_j
\right).
$$

fragment-patch similarity：

$$
S_{k,i}=\cos(t_k,V_i).
$$

Top-K regional score：

$$
r_k=
\frac1R
\sum_{i\in TopR(S_k)}S_{k,i}.
$$

fragment relevance：

$$
a_k=\cos(t_k,g_t),\qquad
\alpha_k=\operatorname{Softmax}(a_k).
$$

Regional alignment：

$$
s_r=\sum_k\alpha_kr_k.
$$

Cross-scope evidence：

$$
e_a=f_a([s_g,s_r]),
$$

其中 $e_a\in\mathbb R^{256}$。

关闭 CSAE 时：

$$
e_a=\mathbf 0.
$$

不改变 CSAE 内部结构。

## 8. Overall MOS Fusion

这是 AIGIQA-20K 唯一新增的必要结构。

固定输入：

$$
z=[v_q,t_0,e_a].
$$

维度：

```text
256 + 256 + 256 = 768
```

推荐：

```python
self.overall_fusion = nn.Sequential(
    nn.Linear(dim * 3, dim),
    nn.GELU(),
    nn.Dropout(0.0),
)
self.overall_head = nn.Linear(dim, 1)
```

输出：

```text
[B, 1]
```

AIGIQA-20K 模型不再保留 `quality_head` 与 `alignment_head`。

## 9. Forward 参考

```python
def forward(self, image, text):
    feat = self.backbone(image, text)

    global_v = feat["global_v"]
    global_t = feat["global_t"]
    hs = feat["vision_hidden"]

    v0 = self.visual_proj(global_v)
    t0 = self.text_proj(global_t)

    if self.use_lqea:
        delta_q = self.lqea(hs[3], hs[6], hs[9], hs[12])
        vq = v0 + torch.tanh(self.quality_gate) * delta_q
    else:
        vq = v0

    if self.use_csae:
        ea, sg, sr = self.csae(
            hs[12],
            feat["text_tokens"],
            feat["attention_mask"],
            global_v,
            global_t,
            self.backbone.clip.visual_projection,
            self.backbone.clip.text_projection,
        )
    else:
        ea = torch.zeros_like(v0)

    h = self.overall_fusion(torch.cat([vq, t0, ea], dim=-1))
    mos = self.overall_head(h)
    return mos
```

关键要求：

# 全程不得出现 `.detach()`。

## 11. 消融公平性

## 17. Loss

单一 MOS 使用 MSE：

$$
L_{\mathrm{MOS}}
=
\frac1N\sum_i(\hat y_i-y_i)^2.
$$

禁止新增 ranking loss、Pearson loss、contrastive loss、multi-task loss 或 consistency loss。

## 22. Full 的理想情况

```text

<

```

## 23. Full 可接受情况

若：

```text
B1 > B0
B2 > B0
B3 > B0
```

且 B3 与 `max(B1,B2)` 的 MainScore 差距在 `±0.001` 内，也可接受。

说明两个模块都有效，但在综合 MOS 上存在部分信息重叠。

此时不需要继续改模块。

## 24. 某个模块无效时

例如：

```text
B1 > B0
B2 ≈ B0 或 B2 < B0
```

先检查：

1. CSAE/LQEA gradient 是否正常；
2. image-prompt 是否正确配对；
3. CSAE evidence 是否非退化；
4. 四组初始化是否一致；
5. best checkpoint 是否按同一 MainScore 规则选择。

如果实现全部正确，再判断模块在 AIGIQA-20K 上泛化不足。

不要立刻加新模块。

## 25. Full 出现负交互时

如果两个单模块都有效，但 Full 明显变差，例如：

```text
B1 = +0.006
B2 = +0.005
B3 = +0.001
```

先检查：

```text
matched init
fusion zero placeholder
best epoch
gradient routing
```

不要马上加 gate、attention、loss 或调 LoRA rank。

本实验到结果诊断为止。
