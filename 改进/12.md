## 3.3 Final MLPQ 结构

### Step 1：Multi-Level Projection

输入：

```text
H3
H6
H9
H12
```

去掉 CLS token 后分别投影：

$$
P_l=W_l(\operatorname{LN}(H_l)),
\quad
l\in\{3,6,9,12\}.
$$

推荐保持：

```text
width = 768
dim   = 256
```

### Step 2：Multi-Level Patch Representation

继续使用已经明确验证有效的简单平均：

$$
P=
\frac{
P_3+P_6+P_9+P_{12}
}{4}.
$$

不要改成：

```text
learned layer weights
attention fusion
cross-level transformer
DASF
HMQE
```

这些方向已经做过，不再恢复。

### Step 3：Quality-Aware Patch Weighting

删除 deviation 后，直接：

$$
w_i=
\sigma(f_w(P_i)).
$$

建议结构：

```python
self.patch_weight = nn.Sequential(
    nn.Linear(dim, max(dim // 2, 8)),
    nn.GELU(),
    nn.Linear(max(dim // 2, 8), 1),
)
```

注意：

```text
输入维度从 dim+1 改成 dim
```

彻底删除：

```text
quality_global_proj
_last_deviation
semantic deviation
zero deviation channel
```

### Step 4：Weighted Quality Aggregation

$$
q_{\text{local}}
=
\frac{
\sum_i w_iP_i
}{
\sum_iw_i+\epsilon
}.
$$

保持：

```python
self.quality_out = nn.Sequential(
    nn.Linear(dim, dim),
    nn.GELU(),
    nn.LayerNorm(dim),
)
```

得到：

$$
\Delta v_q=f_q(q_{\text{local}}).
$$

模型外部继续：

$$
v_q=
v_0+
\tanh(\lambda_q)\Delta v_q.
$$

# 4. Final MGSC：保留完整 global-local 机制，删除重复 scalar residual

## 4.1 当前 V23 MGSC

当前：

```text
Global similarity s_g
+
Token-chunk fragment → patch Top-K
+
Fragment importance weighting
→ local similarity s_l
+
beta fusion
→ s_align
+
[s_g, s_l] → sem_proj → s_embed
+
lambda_msc * s_align residual
```

日志显示：

```text
mgsc_local_sim_std ≈ 0.02 ~ 0.03
```

说明 local correspondence 确实有样本区分度。

但：

```text
mgsc_beta ≈ 0.500 ~ 0.501
mgsc_align_ratio ≈ 0.001
```

说明：

```text
learnable beta 几乎没有移动
直接 scalar residual 贡献非常小
```

同时：

```text
[s_g, s_l] → s_embed
```

已经直接进入 alignment fusion。

因此最终只删除：

```text
beta scalar fusion
lambda_msc scalar residual
```

保留其余有利于形成完整 MGSC 链条的部分。

# 6. Final MGSC 具体结构

## 6.1 Global Correspondence

保持：

$$
s_g=
\cos(v_g,t_g).
$$

即：

```text
Global Image
↕
Global Prompt
```

用于判断整体语义一致性。

## 6.2 Local Textual Fragments

继续使用当前低成本、可复现设计：

```text
把有效 CLIP text tokens 顺序切成 K 个连续 chunk
```

默认：

```text
K = 4
```

注意论文/注释术语：

### 可以写

```text
textual fragments
contiguous prompt token groups
local textual groups
```

### 不要写

```text
noun phrases
object-attribute phrases
semantic parser
LLM-generated fragments
```

因为当前实现并没有做真正的句法/语义切分。

## 6.3 Fragment-Patch Matching

对第 $k$ 个 textual fragment：

$$
t_k=
\operatorname{Norm}
\left(
\frac{1}{|F_k|}
\sum_{j\in F_k}T_j
\right).
$$

image patch features：

$$
V_i.
$$

相似度：

$$
S_{k,i}
=
\cos(t_k,V_i).
$$

## 6.4 Top-K Local Evidence

保持：

```text
topk = 3
```

$$
c_k=
\frac1r
\sum_{i\in TopK(S_{k,:})}
S_{k,i}.
$$

解释：

> 一个 textual fragment 只需要在最相关的少量 image regions 中寻找对应视觉证据，不应被大量无关 patch 稀释。

这一环节保留。

## 6.5 Fragment-Aware Aggregation

虽然当前 fragment weight 接近均匀，但这一环节：

```text
参数极少
逻辑合理
有助于形成完整 local correspondence 流程
```

因此保留。

计算：

$$
a_k=
\cos(t_k,t_g),
$$

$$
\alpha_k=
\operatorname{Softmax}(a_k),
$$

$$
s_l=
\sum_k\alpha_kc_k.
$$

论文中不要把它单独写成重大创新。

表述为：

> Fragment-wise local correspondence evidence is aggregated according to its relevance to the global prompt representation.

即可。

# 7. 删除 beta scalar fusion

删除：

```python
self.eta
beta = torch.sigmoid(self.eta)
s_align = beta * s_g + (1 - beta) * s_l
```

Final MGSC 不再显式计算 scalar：

$$
s_{\text{align}}.
$$

原因：

1. $\beta$ 基本保持 0.5；
2. global/local 信息已经由 correspondence embedding 自适应融合；
3. 避免两套重复 fusion。



即：

$$
h_a=
f_a([v_a,t_a,e_c]),
$$

$$
\hat y_a=W_ah_a+b_a.
$$

```text

outer MGSC residual
mgsc_align_ratio
```

# 17. 第二阶段：MLPQ Mean vs Learned Weighting

目标：

> 判断 MLPQ 中 learned patch weighting 是否值得保留为完整机制的一部分。

实现一个开关：

```text
mlpq_pool = "mean"
mlpq_pool = "weighted"
```

## Mean

$$
q_{\text{local}}^{mean}
=
\frac1N\sum_iP_i.
$$

## Weighted

$$
q_{\text{local}}^{weighted}
=
\frac{\sum_iw_iP_i}
{\sum_iw_i+\epsilon}.
$$

---

# 18. MLPQ weighting 判定

优先 split5。

如果：

```text
Weighted - Mean >= +0.002 Q-SRCC
```

则：

# learned patch weighting 明确保留

并补 split6。

如果：

```text
+0.001 ~ +0.002
```

仍可保留，作为内部 aggregation operator，但论文不要单独宣称巨大贡献。

如果：

```text
< +0.001
```

且两个 split 都如此：

> 可以考虑最终改成 mean pooling。

但是：

如果 weighted 与 mean 几乎持平，**为了模块完整度也允许保留 weighted**，前提是：

1. 参数增加很小；
2. 不导致性能下降；
3. 论文中仅作为 MLPQ 内部 aggregation，不独立宣称创新。

不要因为这个结果再设计新的 patch weighting。

# 20. MGSC 核心消融想看到的模式

希望：

```text
Global only       → 有基础 alignment 能力
Local only        → 捕获局部 correspondence
Global + Local    → 最优
```

最关键比较：

$$
\text{Global+Local}
-
\text{Global only}.
$$

如果：

```text
>= +0.003 A-SRCC
```

则 local correspondence 有明确价值。

如果只：

```text
+0.001 ~ +0.003
```

仍可保留，因为 split6 已经显示 MGSC 有较大整体增益，但论文措辞要克制。

如果：

```text
< +0.001
```

两个 split 都如此，则说明 MGSC 的 local granularity 需要重新评估。

但不要立刻设计新模块；先确认实现/数据流无误。

# 29. 初始化与公平性

## 29.1 MGSC Slim 验证

MGSC 的主要 `correspondence_proj` 与原 `sem_proj` 结构相同：

```text
Linear(2,D)
GELU
LayerNorm(D)
```

因此：

> Refined MGSC 可以从 V23 matched init 中直接复制 `sem_proj` 参数到 `correspondence_proj`。

删除的：

```text
eta
lambda_msc
```

无需迁移。

这样第一阶段尽量保持初始化公平。

## 29.2 Clean MLPQ 参数迁移

原 no-deviation `patch_weight` 第一层：

```text
Linear(dim+1, dim//2)
```

最后一个输入列对应恒为 0 的 deviation。

新 MLPQ：

```text
Linear(dim, dim//2)
```

可以迁移：

```python
new.patch_weight[0].weight.copy_(
    old.patch_weight[0].weight[:, :dim]
)
new.patch_weight[0].bias.copy_(
    old.patch_weight[0].bias
)
```

其它：

```text
patch_proj
quality_out
patch_weight second Linear
```

直接复制。

因此 clean MLPQ 可以与 V23 no-deviation MLPQ 做到几乎 function-equivalent migration。

不要随机重置后就拿一次结果直接和 V23 下结论。

# 32. 最终论文方法故事

## Problem 1：视觉质量

AIGC degradation 不是只存在于 CLIP 最终层：

```text
低层：
texture / sharpness / artifacts

中层：
local structure / shape

高层：
semantic structure
```

因此：

# MLPQ

```text
Multi-Level Representation
        ↓
Quality-Aware Patch Aggregation
        ↓
Perceptual Quality Feature
```

仅：

$$
\cos(I,T)
$$

只能判断全局语义。

细粒度错误可能包括：

```text
对象缺失
属性错误
数量错误
局部关系不一致
prompt 局部概念未被生成
```

因此：

# MGSC

```text
Global Correspondence
        +
Fragment-Patch Local Correspondence
        ↓
Fragment-Aware Aggregation
        ↓
Global-Local Correspondence Embedding
```
