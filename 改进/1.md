# V14 改进方案：从当前 V13/V12 迁移到 MSRC Alignment Module

> 当前基线 commit：`1edfb7120efc53a6a9cf920ab1998f0939e7c3bf`
>
> 目标：保留已经验证有效的 DG-MPQ Quality 分支，停止 MSCM / PCGrad 路线，新增一个完整但低辨识度的 Alignment 模块：
>
> **MSRC — Multi-Level Semantic Relation Calibration**
>
> 核心逻辑：
>
> ```text
> Multi-Level Semantic Refinement
>              ↓
> Cross-Modal Relation Modeling
>              ↓
> Relation Confidence Calibration
>              ↓
> Alignment Representation
> ```

## 1. 为什么切换到 MSRC

当前实验已经说明：

```text
V12 Full:
Q-SRCC = 0.8605
A-SRCC = 0.7309

V13 Full-PCGrad:
Q-SRCC = 0.8607
A-SRCC = 0.7360
```

PCGrad 没有恢复 Quality，因此不再继续围绕优化器修 MSCM。

同时：

```text
R0 A-SRCC = 0.7321
B2-MSCM   = 0.7328
提升       = +0.0007
```

MSCM 本身的独立增益过弱，不足以作为第二贡献。

V14 的核心变化：

```text
MSCM:
patch-wise spatial correspondence

→

MSRC:
multi-level semantic refinement
+ explicit cross-modal relation
+ confidence calibration
```

# 2. V14 总体结构

```text
                              CLIP ViT-B/16
                                   │
                             Visual LoRA
                                   │
                   ┌───────────────┴───────────────┐
                   │                               │
               Quality                         Alignment
                   │                               │
          H3/H6/H9/H12                      H9/H12/Global
                   │                               │
                DG-MPQ                            MSRC
                   │                               │
                  v_q                            a_rel
                   │                               │
            Quality Fusion                 Alignment Fusion
                   │                               │
             Quality Head                   Alignment Head
                   │                               │
                  Q                               A
```

V14 第一轮额外采用：

> **Alignment loss 不回传到 Visual LoRA。**

即：

```text
L_Q → Visual LoRA → DG-MPQ → Q
L_A → MSRC / Alignment Projection / Fusion / Head
```

Alignment 仍读取 LoRA 后的视觉特征，但进入 Alignment 分支前执行 `detach()`。

这样第一轮可以干净回答：

```text
1. MSRC 自己是否有效？
2. Full 是否能保住 B1 的 Quality？
```

# 3. MSRC 三个子模块

MSRC 包含：

```text
1. MSR
Multi-Level Semantic Refinement

2. CMR
Cross-Modal Relation Modeling

3. RCC
Relation Confidence Calibration
```

数据流：

```text
                 H9 patches
                     │
                 Mean Pool
                     │
             Projection + Adapter
                     │
                     ├──────────────┐
                     │              │
                H12 patches        │
                     │              │
                 Mean Pool         │
                     │              │
             Projection + Adapter  │
                     │              │
                     └──────┬───────┘
                            │
                    Text-conditioned
                       Level Gate
                            │
                           v_s
                            │
                  ┌─────────┴─────────┐
                  │                   │
               W_v(v_s)            W_t(t)
                  │                   │
                  ├──── Hadamard ─────┤
                  │                   │
                  └──── |v - t| ──────┘
                            │
                   + Global CLIP Cos
                            │
                     Relation Encoder
                            │
                           r_c
                            │
                 Confidence Calibration
                            │
                         r_hat
                            │
                  [v_a, t_a, r_hat]
                            │
                    Alignment Fusion
                            │
                     Alignment Head
                            │
                            A
```

# 4. MSR：Multi-Level Semantic Refinement

输入：

```text
H9  : [B,197,768]
H12 : [B,197,768]
```

丢弃 CLS 后平均：

$$
p_9=\operatorname{Mean}(H_9[:,1:,:])
$$

$$
p_{12}=\operatorname{Mean}(H_{12}[:,1:,:])
$$

投影：

```text
LayerNorm(768)
→ Linear(768,256)
```

得到：

$$
v_9,\;v_{12}\in\mathbb R^{256}
$$

之后各自经过 residual adapter：

$$
\tilde v_9=v_9+\tanh(\alpha_9)A_9(v_9)
$$

$$
\tilde v_{12}=v_{12}+\tanh(\alpha_{12})A_{12}(v_{12})
$$

Adapter：

```text
Linear(256,64)
→ GELU
→ Linear(64,256)
```

建议：

```text
bottleneck = 64
alpha9 init = 0.01
alpha12 init = 0.01
```

---

# 5. Text-conditioned Level Gate

不直接平均 H9/H12，而让文本决定各语义通道更依赖哪个层级：

$$
g=
\sigma
\left(
W_g[
\tilde v_9;
\tilde v_{12};
t
]
\right)
$$

结构：

```text
Linear(768,256)
→ GELU
→ Linear(256,256)
→ Sigmoid
```

融合：

$$
v_s=
g\odot\tilde v_9+
(1-g)\odot\tilde v_{12}
$$

使用 channel-wise gate。

建议记录：

```text
level_gate_mean
level_gate_std
```

---

# 6. CMR：Cross-Modal Relation Modeling

先把视觉和文本映射到低秩 relation space：

$$
z_v=W_vv_s
$$

$$
z_t=W_tt
$$

建议：

```text
relation_rank = 128
Wv: 256 -> 128
Wt: 256 -> 128
```

## 6.1 Multiplicative relation

$$
r_{\mathrm{mul}}
=
\operatorname{GELU}(z_v)
\odot
\operatorname{GELU}(z_t)
$$

表示视觉与文本同时激活的语义维度。

## 6.2 Difference relation

$$
r_{\mathrm{diff}}
=
|z_v-z_t|
$$

表示视觉与文本的语义 mismatch。

## 6.3 Global CLIP correspondence

继续保留 CLIP 原始 projection space 的 cosine：

$$
s_g=
\cos(
v_{\mathrm{global}},
t_{\mathrm{global}}
)
$$

不要用 256D task projection 重新计算。

## 6.4 Relation Encoder

拼接：

$$
r_{\mathrm{raw}}
=
[
r_{\mathrm{mul}};
r_{\mathrm{diff}};
s_g
]
$$

relation rank=128 时：

```text
128 + 128 + 1 = 257
```

编码：

```text
Linear(257,256)
→ GELU
→ Dropout
→ LayerNorm(256)
```

得到：

$$
r_c\in\mathbb R^{256}
$$

---

# 7. RCC：Relation Confidence Calibration

预测 channel-wise relation confidence：

$$
c=
\sigma
\left(
W_c[
v_s;
t;
r_c;
s_g
]
\right)
$$

输入维度：

```text
256 + 256 + 256 + 1 = 769
```

结构：

```text
Linear(769,256)
→ GELU
→ Linear(256,256)
→ Sigmoid
```

得到：

```text
c: [B,256]
```

校准：

$$
\hat r=c\odot r_c
$$

输出：

```text
a_rel = r_hat
```

日志：

```text
confidence_mean
confidence_std
relation_norm
global_cos
```

# 8. 新增 `msrc.py`

新增文件：

```text
v8/ipiqa/models/msrc.py
```

建议第一版直接实现：

```python
import torch
import torch.nn as nn
import torch.nn.functional as F


class ResidualAdapter(nn.Module):
    def __init__(self, dim=256, bottleneck=64, init_scale=0.01):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(dim, bottleneck),
            nn.GELU(),
            nn.Linear(bottleneck, dim),
        )
        self.scale = nn.Parameter(torch.tensor(float(init_scale)))

    def forward(self, x):
        return x + torch.tanh(self.scale) * self.net(x)


class MSRC(nn.Module):
    def __init__(
        self,
        visual_width=768,
        dim=256,
        relation_rank=128,
        adapter_ratio=4,
        drop=0.0,
        init_scale=0.01,
    ):
        super().__init__()

        bottleneck = max(dim // adapter_ratio, 8)

        # 1. Multi-Level Semantic Refinement
        self.proj9 = nn.Sequential(
            nn.LayerNorm(visual_width),
            nn.Linear(visual_width, dim),
        )
        self.proj12 = nn.Sequential(
            nn.LayerNorm(visual_width),
            nn.Linear(visual_width, dim),
        )

        self.adapter9 = ResidualAdapter(
            dim, bottleneck, init_scale
        )
        self.adapter12 = ResidualAdapter(
            dim, bottleneck, init_scale
        )

        self.level_gate = nn.Sequential(
            nn.Linear(dim * 3, dim),
            nn.GELU(),
            nn.Linear(dim, dim),
            nn.Sigmoid(),
        )

        # 2. Cross-Modal Relation Modeling
        self.rel_v = nn.Linear(dim, relation_rank)
        self.rel_t = nn.Linear(dim, relation_rank)

        self.relation_encoder = nn.Sequential(
            nn.Linear(relation_rank * 2 + 1, dim),
            nn.GELU(),
            nn.Dropout(drop),
            nn.LayerNorm(dim),
        )

        # 3. Relation Confidence Calibration
        self.confidence = nn.Sequential(
            nn.Linear(dim * 3 + 1, dim),
            nn.GELU(),
            nn.Linear(dim, dim),
            nn.Sigmoid(),
        )

        self._last_stats = None

    def forward(self, h9, h12, t, global_v, global_t):

        # ---------- MSR ----------
        p9 = h9[:, 1:, :].mean(dim=1)
        p12 = h12[:, 1:, :].mean(dim=1)

        v9 = self.adapter9(self.proj9(p9))
        v12 = self.adapter12(self.proj12(p12))

        gate = self.level_gate(
            torch.cat([v9, v12, t], dim=-1)
        )

        v_s = gate * v9 + (1.0 - gate) * v12

        # ---------- CMR ----------
        z_v = self.rel_v(v_s)
        z_t = self.rel_t(t)

        r_mul = F.gelu(z_v) * F.gelu(z_t)
        r_diff = torch.abs(z_v - z_t)

        gv = F.normalize(global_v, dim=-1)
        gt = F.normalize(global_t, dim=-1)

        s_global = (
            gv * gt
        ).sum(dim=-1, keepdim=True)

        r_raw = torch.cat(
            [r_mul, r_diff, s_global],
            dim=-1,
        )

        r_c = self.relation_encoder(r_raw)

        # ---------- RCC ----------
        conf = self.confidence(
            torch.cat(
                [v_s, t, r_c, s_global],
                dim=-1,
            )
        )

        r_hat = conf * r_c

        self._last_stats = {
            "level_gate_mean":
                round(gate.mean().item(), 4),
            "level_gate_std":
                round(gate.std().item(), 4),
            "confidence_mean":
                round(conf.mean().item(), 4),
            "confidence_std":
                round(conf.std().item(), 4),
            "global_cos":
                round(s_global.mean().item(), 4),
            "relation_norm":
                round(
                    r_hat.norm(dim=-1).mean().item(),
                    4,
                ),
        }

        return r_hat
```

# 18. 为什么第一版必须 stop-gradient

如果不 detach：

```text
MSRC
→ 改 L_A
→ 改 Shared Visual LoRA
→ 改 Quality feature
```

又会回到 V12 的归因问题。

第一版：

```python
h9_a = hs[9].detach()
h12_a = hs[12].detach()
global_v_a = global_v.detach()
```

此时：

```text
L_A 不更新 Visual LoRA
```

但仍更新：

```text
alignment_visual_proj
alignment_text_proj
MSRC
alignment_fusion
alignment_head
```

于是：

```text
B1-Q ≈ Full-Q
```

这是 V14 第一轮最重要的结构约束。

# 42. 两个贡献最终的完整度

最终方法图可以对称为：

```text
Quality Branch

Multi-Level Patch Representation
        ↓
Local-Global Deviation Modeling
        ↓
Deviation-Guided Patch Aggregation
        ↓
Quality Representation
```

以及：

```text
Alignment Branch

Multi-Level Semantic Refinement
        ↓
Cross-Modal Relation Modeling
        ↓
Relation Confidence Calibration
        ↓
Alignment Representation
```

所以第二模块不会只是一个简单 Adapter 或一个乘法算子，而是和 DG-MPQ 一样具有完整的内部逻辑链。

# 43. 最终决策规则

## 保留 MSRC

如果：

```text
B2 A >= R0 A + 0.006
```

同时：

```text
Full Q ≈ B1 Q
```

则继续。

## 谨慎保留

如果：

```text
A gain = +0.003 ~ +0.005
```

再跑一个 split 验证。

## 直接放弃

如果：

```text
A gain < +0.003
```

尤其接近：

```text
+0.001
```

就停止，不再投入多个版本修补。

# 44. 一句话总结

V14 从当前代码迁移时，**DG-MPQ、backbone、loss、trainer 主流程都不动**；新增 `msrc.py` 与 `model_v14.py`，把 MSCM 的 patch-wise spatial correspondence 改成：

```text
Multi-Level Semantic Refinement
+
Cross-Modal Match/Mismatch Relation
+
Confidence Calibration
```

同时第一轮在 Alignment 输入处 stop-gradient，使 `L_A` 不再更新 Visual LoRA。

这样可以先非常干净地判断：

```text
MSRC 到底有没有真正的 Alignment 增益
```

而不是再次把模块效果和共享训练动态混在一起。
