# V8 最终改进方案：V8-Slim Final

## 1. 最终结论

最终建议冻结为：

**CLIP ViT-B/16 + Visual Q/K LoRA + DG-MPQ + Slim HCMI-ViT**

其中：

- Visual LoRA：作为轻量 backbone adaptation，不作为创新点；
- DG-MPQ：Quality-oriented 主模块；
- HCMI-ViT：Alignment-oriented 主模块；
- 删除 discrepancy-guided attention bias；
- 删除 MSA-T multi-kernel text enhancement；
- HCMI 内部 MLP 从 `mlp_ratio=2.0` 缩到 `1.0`；
- LoRA dropout 固定为 `0.0`；
- 两个主模块继续保持并行，不串行互相修改输入。

最终不再继续设计 V9，也不再继续砍核心结构。

---

## 2. 为什么定这个版本

上一版完整 V8 的核心问题不是“模型没效果”，而是 HCMI 过重、内部机制太多：

- prompt weighting
- MSA-T
- discrepancy-guided attention bias
- detail-level bidirectional cross-attention
- semantic-level bidirectional cross-attention
- 两套大 MLP
- hierarchy gate
- outer residual gate

日志已经说明：

### 2.1 discrepancy-guided bias 没有足够证据

旧版中：

```text
beta_align ≈ 0.002 ~ 0.003
```

而 bias 为：

```text
bias = -tanh(beta_align) * discrepancy
```

因此实际 attention bias 非常弱。

同时整个 HCMI branch 的：

```text
align_ratio ≈ 0.15
```

说明 HCMI 本身在工作，但大概率并不是 discrepancy bias 在起主要作用。

因此该部分删除。

---

### 2.2 MSA-T 参数很大，但收益有限

MSA-T 包括：

```text
Conv1d k=3
Conv1d k=5
Conv1d k=7
Concat
1x1 Conv
GELU
Residual
```

参数量约：

```text
≈ 1.18M
```

当前 S1 与 S2 的统一 best-joint 对比为：

| Model | Q-SRCC | Q-PLCC | A-SRCC | A-PLCC |
|---|---:|---:|---:|---:|
| S1 Slim + MSA-T | 0.85113 | 0.91278 | 0.71285 | 0.84298 |
| S2 Slim w/o MSA-T | 0.84657 | 0.91098 | 0.71407 | 0.84394 |

删除 MSA-T 后：

```text
Q-SRCC  -0.00456
Q-PLCC  -0.00180
A-SRCC  +0.00122
A-PLCC  +0.00096
```

也就是说：

- Alignment 基本完全保留；
- Quality 只有小幅下降；
- 可删除约 1.18M 参数；
- HCMI 结构明显更容易解释。

因此最终采用 **no-MSA** 版本。

# 5. DG-MPQ 最终保留方案

DG-MPQ 是目前证据最强的主模块，不建议继续大改。

最终保留：

```text
L3 patch tokens
L6 patch tokens
L9 patch tokens
L12 patch tokens
        ↓
multi-level projection / aggregation
        ↓
global CLS anchor
        ↓
local-global semantic deviation
d_i = 1 - cos(p_i, g)
        ↓
deviation-guided patch weighting
        ↓
weighted patch aggregation
        ↓
quality residual Δq
```

核心代码逻辑：

```python
P3 = proj3(H3_patch)
P6 = proj6(H6_patch)
P9 = proj9(H9_patch)
P12 = proj12(H12_patch)

P = (P3 + P6 + P9 + P12) / 4

g = global_proj(H12_cls)

d = 1 - cosine(P, g)

w = sigmoid(weight_mlp([P, d]))

q_local = sum(w * P) / sum(w)

delta_q = quality_out(q_local)
```

最终：

```python
v = v0 + torch.tanh(lambda_q) * delta_q
```

# 10. HCMI-ViT 最终伪代码

最终可以收敛成：

```python
class HcmiVit(nn.Module):

    def forward(self, h6, h12, text_tokens, text_mask):

        detail = self.detail_proj(h6)
        semantic = self.semantic_proj(h12)

        T = self.text_token_proj(text_tokens)

        # prompt weighting
        score = self.prompt_gate(T).squeeze(-1)
        score = score.masked_fill(~text_mask, -inf)

        probs = softmax(score, dim=1)
        valid_len = text_mask.sum(dim=1, keepdim=True).clamp_min(1)

        weight = probs * valid_len
        T = T * weight.unsqueeze(-1)

        # detail-level bidirectional interaction
        V_d = detail + self.alpha_d * self.detail_cross_v(
            detail, T, mask=text_mask
        )

        T_d = T + self.beta_d * self.detail_cross_t(
            T, detail
        )

        # semantic-level bidirectional interaction
        V_s = semantic + self.alpha_s * self.semantic_cross_v(
            semantic, T, mask=text_mask
        )

        T_s = T + self.beta_s * self.semantic_cross_t(
            T, semantic
        )

        # per-level representations
        C_d = self.mlp_d(
            cat(
                mean(V_d),
                masked_mean(T_d)
            )
        )

        C_s = self.mlp_s(
            cat(
                mean(V_s),
                masked_mean(T_s)
            )
        )

        # hierarchy fusion
        gate = sigmoid(
            self.hierarchy_gate(
                cat(C_d, C_s)
            )
        )

        delta_a = gate * C_d + (1 - gate) * C_s

        return self.align_out_norm(delta_a)
```

外层：

```python
c = t0 + torch.tanh(lambda_a) * delta_a
```
