# IQtest v8：CLIP-ViT + PEFT + DG-MPQ + DP-HCMI 缝合方案

> 目标：停止在 Frozen CLIP-RN50 后端继续堆叠模块，改为使用更适合 token-level IQA / image-text alignment 的 CLIP ViT 主干，并把已经在 IQA/AGIQA 文献中验证有效的成熟设计进行任务适配。
>
> 本方案不是照抄某一篇论文：LoRA 作为成熟 PEFT 工具；质量分支参考 TeMu-IQA 的 multi-level patch modeling，但改成 AIGC-specific semantic deviation 引导；对齐分支保留当前项目的 DP-HCMI，并针对 ViT token hierarchy 重构。

---

## 1. 最终结构

```text
                 CLIP ViT-B/16
                      |
          Visual Transformer + LoRA
              (PEFT infrastructure)
                      |
        ---------------------------------
        |                               |
 multi-level patch tokens          text tokens
        |                               |
      DG-MPQ                       DP-HCMI-ViT
   Quality Branch                 Alignment Branch
        |                               |
     delta_q                         delta_a
        |                               |
v = v0 + gate_q*delta_q      c = t0 + gate_a*delta_a
        \                               /
         \                             /
             concat(v,c)
                 |
           shared fusion
                 |
          ----------------
          |              |
       Quality        Alignment
        Head            Head
```

两个主模块：

```text
Module 1:
DG-MPQ
Deviation-Guided Multi-Level Patch Quality Module

Module 2:
DP-HCMI-ViT
Discrepancy-aware Prompt-conditioned Hierarchical
Cross-Modal Interaction for ViT
```

LoRA 不作为第三个创新，而是 backbone adaptation strategy。

## 3. 为什么换 CLIP ViT-B/16

当前 RN50 spatial feature：

```text
[B,2048,H,W]
```

为了给跨模态模块使用必须：

```text
Conv1x1
→ flatten
→ transpose
→ pooling
→ fine/coarse token
```

ViT-B/16 在 224×224 下天然得到：

```text
14×14 = 196 patch tokens
[B,197,768]
```

包括 1 个 CLS token + 196 patch tokens。

它天然适合：

```text
local quality modeling
cross-modal attention
prompt discrepancy
multi-level intermediate features
```

建议 backbone：

```text
openai/clip-vit-base-patch16
```

实现优先使用 Hugging Face transformers：

```python
from transformers import CLIPModel

self.clip = CLIPModel.from_pretrained(
    "openai/clip-vit-base-patch16"
)
```

原因：

```text
1. output_hidden_states=True；
2. q_proj/k_proj 独立；
3. PEFT LoRA 容易插入；
4. 中间层 patch token 直接取得；
5. 不需要手改 OpenAI CLIP Transformer。
```

# 6. Module 1：DG-MPQ

全名：

**Deviation-Guided Multi-Level Patch Quality Module**

中文：

```text
语义偏差引导的多层级局部质量建模模块
```

来源：

```text
TeMu-IQA:
multi-level ViT patch representation
+
patch quality weighting

旧 DMSQR:
local-global semantic deviation

最终：
DG-MPQ
```

---

## 6.1 Multi-Level 输入

固定取：

```text
Layer 3
Layer 6
Layer 9
Layer 12
```

每层：

```python
H_l = hidden_states[l]
cls_l = H_l[:,0,:]
patch_l = H_l[:,1:,:]
```

patch token：

```text
[B,196,768]
```

无需 feature-map resize / flatten / transpose。

---

## 6.2 Multi-Level Projection

每层投影：

```python
self.patch_proj = nn.ModuleList([
    nn.Sequential(
        nn.LayerNorm(768),
        nn.Linear(768,256),
    )
    for _ in range(4)
])
```

得到：

```text
P3,P6,P9,P12
[B,196,256]
```

第一版直接平均：

```python
P = (P3 + P6 + P9 + P12) / 4.0
```

不要第一轮再加 attention fusion。

---

## 6.3 Global Quality Anchor

最后层 CLS：

```python
g = self.quality_global_proj(
    H12[:,0,:]
)
```

```python
self.quality_global_proj = nn.Sequential(
    nn.LayerNorm(768),
    nn.Linear(768,256),
)
```

---

## 6.4 Semantic Deviation

对每个 patch：

\[
d_i = 1 - cos(p_i,g)
\]

代码：

```python
p_n = F.normalize(P, dim=-1)
g_n = F.normalize(g, dim=-1).unsqueeze(1)

deviation = 1.0 - (
    p_n * g_n
).sum(dim=-1, keepdim=True)
```

得到：

```text
[B,196,1]
```

含义：

```text
局部 patch 与整图语义偏离明显时，
可能对应结构生成异常、局部纹理崩坏、
不自然细节等 AIGC artifact。
```

这与 prompt discrepancy 不同：

```text
semantic deviation:
patch vs image global

prompt discrepancy:
patch vs user prompt token
```

两个创新维度不会重复。

---

## 6.5 Deviation-Guided Patch Weight

TeMu 的 patch weighting 改成：

```text
patch feature + semantic deviation → importance
```

```python
self.patch_weight = nn.Sequential(
    nn.Linear(257,128),
    nn.GELU(),
    nn.Linear(128,1),
)

weight_input = torch.cat(
    [P,deviation],
    dim=-1
)

w = torch.sigmoid(
    self.patch_weight(weight_input)
)
```

公式：

\[
w_i = sigmoid(MLP([p_i,d_i]))
\]

---

## 6.6 Quality Aggregation

不使用 TeMu 的 Good/Bad quality prompt。

原因：

```text
本项目已经有真实 generation prompt；
如果 Quality 分支再塞 Good/Bad 文本，
容易和 Alignment 分支职责重叠。
```

纯视觉聚合：

\[
q_{local}
=
rac{\sum_i w_i p_i}
{\sum_i w_i+\epsilon}
\]

```python
q_local = (
    w * P
).sum(dim=1) / (
    w.sum(dim=1) + 1e-6
)
```

输出 residual：

```python
self.quality_out = nn.Sequential(
    nn.Linear(256,256),
    nn.GELU(),
    nn.LayerNorm(256),
)

delta_q = self.quality_out(q_local)
```

注入：

```python
v = (
    v0
    + torch.tanh(self.lambda_q)
    * delta_q
)
```

```python
self.lambda_q = nn.Parameter(
    torch.tensor(0.01)
)
```

LayerNorm 只在 proposed residual 内部，不强化 baseline anchor。

## 6.7 与 TeMu-IQA 的区别

| 部分 | TeMu-IQA | DG-MPQ |
|---|---|---|
| Multi-level patch | 有 | 有，参考 |
| Good/Bad quality prompt | 有 | 删除 |
| Text-guided patch score | 有 | 删除 |
| Patch weight | learned visual weight | deviation-guided learned weight |
| Local-global deviation | 无 | 有 |
| AIGC-specific | 非核心 | 核心动机 |
| 输出 | patch-wise quality score | quality residual feature |
| 双任务 | 否 | Quality + Alignment |

论文写法应使用：

```text
inspired by / adapted from
```

不能把 multi-level patch IQA 本身声称为首创。

# 7. Module 2：DP-HCMI-ViT

保留当前项目 DP-HCMI：

```text
Prompt Weighting
Visual-Prompt Discrepancy
Discrepancy-Guided Attention
Bidirectional Cross-Modal Interaction
Adaptive Hierarchical Fusion
Normalized Residual
```

但重新定义 hierarchy。

---

## 7.1 不再使用人工 spatial fine/coarse

旧 RN50：

```text
feature map
→ fine token
→ avg pool
→ coarse token
```

新 ViT：

```text
Detail-level:
Layer 6 patch tokens

Semantic-level:
Layer 12 patch tokens
```

```python
detail_base = self.detail_proj(
    H6[:,1:,:]
)

semantic_base = self.semantic_proj(
    H12[:,1:,:]
)
```

均为：

```text
[B,196,256]
```

优点：

```text
不 resize
不 spatial pooling
不人为对齐不同 backbone feature map
```

hierarchy 来自 pretrained Transformer 的深度。

论文中可以把原 fine/coarse 改称：

```text
detail-level / semantic-level
```

---

## 7.2 Text Token

真实生成 prompt：

```python
T = text_out.last_hidden_state
T = self.text_token_proj(T)
```

得到：

```text
[B,77,256]
```

必须保留 attention mask。

---

## 7.3 Prompt Weighting

沿用 v7 修复：

```python
score = self.prompt_gate(T).squeeze(-1)

score = score.masked_fill(
    attention_mask == 0,
    float("-inf")
)

weight = torch.softmax(score, dim=1)

valid_len = attention_mask.sum(
    dim=1,
    keepdim=True
).clamp_min(1)

weight = weight * valid_len

T_w = T * weight.unsqueeze(-1)
```

保证 padding 不竞争，并维持 token magnitude。

---

## 7.4 Visual-Prompt Discrepancy

\[
D_{ij} = 1 - cos(v_i,t_j)
\]

```python
D_detail = discrepancy(
    detail_base,T_w
)

D_semantic = discrepancy(
    semantic_base,T_w
)
```

bias：

```python
bias_detail = (
    -torch.tanh(self.beta_align)
    * D_detail
)

bias_semantic = (
    -torch.tanh(self.beta_align)
    * D_semantic
)
```

只保留一次 `tanh(beta_align)`，禁止 double gating。

---

## 7.5 Hierarchical Cross-Modal Interaction

分别做：

```text
detail visual ↔ prompt
semantic visual ↔ prompt
```

得到：

```text
C_detail
C_semantic
```

再做：

```python
g_h = torch.sigmoid(
    self.hierarchy_gate(
        torch.cat(
            [C_detail,C_semantic],
            dim=-1
        )
    )
)

delta_a = (
    g_h * C_detail
    + (1.0-g_h) * C_semantic
)

delta_a = self.align_out_norm(
    delta_a
)
```

注入：

```python
c = (
    t0
    + torch.tanh(self.lambda_a)
    * delta_a
)
```

```python
self.lambda_a = nn.Parameter(
    torch.tensor(0.01)
)
```

# 9. Loss

第一轮继续纯 MSE：

```python

    pred_q,target_q
)

loss_a = F.mse_loss(
    pred_a,target_a

```

```python
    images,
```


# 15. 为什么这不是完全照抄

LoRA：

```text
成熟 PEFT 工具，不声称原创。
```

Multi-level patch：

```text
受 TeMu-IQA 启发，不声称首次提出。
```

我们的主要 adaptation：

```text
1. 不用 TeMu 的 Good/Bad quality prompts；
2. 不复制 Text-Guided Patch Scoring；
3. 用 local-global semantic deviation 引导 patch weighting；
4. 输出 quality residual feature，而不是直接 patch scalar；
5. 和真实 user prompt 的 DP-HCMI 双任务协同。
```

DP-HCMI：

```text
受 CHPNet hierarchical cross-modal perception 启发，
但加入：
prompt weighting
visual-prompt discrepancy
discrepancy bias
mask-aware scaling
ViT semantic-depth hierarchy
```

因此项目应该诚实写：

```text
inspired by
adapted from
built upon
```

而不是声称 donor 基础组件完全原创。

# 24. 最终一句话

```text
CLIP ViT-B/16
+
Visual Q/K LoRA
+
Deviation-Guided Multi-Level Patch Quality
+
Discrepancy-aware Prompt-conditioned Hierarchical Cross-Modal Interaction

Shared Fusion
```

其中：

